1.1 · ရည်ရွယ်ချက် & အခြေခံ

တစ်ခုစီ နှင့် တိုင်း နှစ်ခုစလုံးကို "တစ်ခုစီ/တိုင်း" ဟုု ဘာသာပြန်ဆိုထားသော စာအုပ်ဖလှယ်နိုင်သော ( each time / every time )။ ခြားနားချက်မှာ တည်သည်၊ အမြင် : တစ်ခုစီ = ကြည့် တစ်ခုချင်းစီ၊ တစ်ဦးချင်းစီ (X + X + X); တိုင်း = ကြည့် အဖွဲ့တစ်ခုလုံး ၊ အဓိပ္ပါယ်နီးစပ်တယ်။ အားလုံး . ခက်ခဲသော စည်းမျဉ်းအချို့လည်း ရှိပါသည်။ တစ်ခုစီ သုံးနိုင်သည်။ ဟိုင်း ဒုတိယအနေနှင့် တစ်ယောက်တည်းရပ်တည်ပါ။ သာ တိုင်း အတွက်အသုံးပြုသည်။ အကြိမ်ရေ .

Study each sentence carefully. (တစ်ကြိမ်လျှင် စာကြောင်းတစ်ကြောင်း)
Every sentence must have a verb. (ယေဘုယျအားဖြင့် ဝါကျတိုင်း)

1.2 · Core ဖော်မြူလာ

each / every + N singular + V singular အခန်းတစ်ခုစီသည် မတူညီပါ။ ထိုင်ခုံတိုင်းကို ယူ၊ တစ်ယောက်နဲ့တစ်ယောက် (တစ်ယောက်ထဲ) / တစ်ယောက်နဲ့တစ်ယောက်မတူကွဲပြား၊ တစ်ယောက်နဲ့တစ်ယောက် မတူတာ each of + the/these/them + N အများကိန်း စာအုပ်တစ်အုပ်စီသည် မတူညီသောအရောင်များ အဲဒီစာအုပ်ထဲက တစ်အုပ်တိုင်းကို ငါဖတ်ဖူးတယ်။ (နံပါတ်-တိုင်း) ဝါကျရဲ့ အလယ်/အဆုံးမှာ တစ်ယောက်ချင်းစီကို စာအုပ်တစ်အုပ်စီ ပေးတော်မူပါ၊ တစ်ယောက်ကို 40p ကျ every + time (ကြိမ်နှုန်း) နေ့တိုင်း၊ ဆယ်မိနစ်တိုင်း (နေ့စဉ်)
Each one each

the amount used less often; 2 types can be used. Usually used in large numbers. Not used for 2.

1.3 · A. တစ်ခုစီ = တစ်ခုစီ; every = အဖွဲ့အစု

  • တစ်ခါတစ်ရံနှစ်ခုစလုံးကို Each time / Every time I see you, you look different. · There are computers in each / every classroom. သုံးမျိူး၊
  • တစ်ခုစီ သေးငယ်သော နံပါတ်များနှင့် တူညီသည်- There were four books. Each book was a different colour. · Each player has three cards.
  • တိုင်း နံပါတ်ကြီးရေပန်းစားသည်- She has read every book in the library. · I'd like to visit every country in the world.

1.4 · B. ခက်ခဲသောနည်းလမ်းများ

  • နှစ်ခု → တစ်ခုစီ : In football, each team has eleven players. (နံပါတ် အသင်းတိုင်း )
  • ကြိမ်နှုန်း → တိုင်း : 'How often?' 'Every day.' · a bus every ten minutes (နံပါတ် နေ့တိုင်း ).

1.5 · C. ပူးတွဲဖွဲ့စည်းပုံ

  • တစ်ခုစီ + N / တစ်ခုစီ တစ်ယောက်တည်း/ တစ်ခုစီ : None of the rooms were the same. Each (one) was different.
  • တိုင်း → တစ်ယောက်တည်းမနေပါနဲ့။ တစ်ခုချင်းစီ : 'Have you read all these books?' 'Yes, every one.'
  • အသီးအသီး the/thes/them- Each of the books is ... (အနည်းကိန်းကြိယာ)
  • တစ်ခုချင်းစီ (မရရှိနိုင်ပါ တိုင်း ): I've read every one of them.
  • တစ်ခုစီ ဝါကျတစ်ခု၏ အလယ်/အဆုံးတွင် The students were each given a book. · These oranges cost 40p each.

1.6 · D. လူတိုင်း vs လူတိုင်း

  • လူတိုင်း (၁) = လူတိုင်းအတွက်သာ သုံးသည်။ လူတွေ : Everyone enjoyed the party.
  • တစ်ခုချင်းစီ (စကားလုံး 2 လံုး) = အုပ်စုရှိ လူစီ/လူ ကြီး (≈ တစ်ခုစီ): She's invited to lots of parties and goes to every one.

2.1 · လက်တွေ့ဘဝဥပမာ 8 ခု (ဘဝ · အလုပ် · စာမေးပွဲများ)

⚽ Each team has eleven players. (အားကစား - နှစ်သင်း)
🚇 The metro runs every five minutes. (ခရီးသွား — အကြိမ်ရေ)

👩‍🏫 The students were each given a laptop. (ကျောင်း — ဝါကျတစ်ခု၏အလယ်တွင် တစ်ခုစီ)

2.2 · မှတ်ဉာဏ်အကြံပြုချက်များ 🧠

  • တစ်ခုစီ = "တစ်ခုစီ" တိုင်း = "တိုင်း" ။ လူတစ်ဦးစီသည် လက်ဆောင်များ → တစ်ခုစီ ရရှိသည်; လူတိုင်း → လူတိုင်းဖြစ်ရမည်။
  • နံပါတ် 2 → တစ်ခုစီ။ လက်နှစ်ချောင်း၊ အဖွဲ့နှစ်ဖွဲ့၊ နှစ်ဖက် → လက်တစ်ဖက်စီ၊ တစ်သင်းစီ၊ တစ်ဖက်စီ။
  • အချိန်ဇယား → တိုင်း။ နေ့တိုင်း၊ အပတ်တိုင်း၊ ၃ လတစ်ကြိမ်။
  • လူတိုင်း "တစ်ယောက်တည်း" မသွားဘူး "go with of" → ချေးစရာမလိုပါ။ တစ်ခု : every one (of).
  • လူတိုင်း = လူ၊ လူတိုင်း = ပြောသောအုပ်စုရှိ အရာ/လူ။

2.3 · အကြံပြုချက်များကို ရယူစမ်းသပ်ခြင်း။

  • ဗလာ → ပြီးနောက် of အမျိုးအစား တစ်ခုစီ (သို့မဟုတ်) လူတိုင်း။
  • နံပါတ် + အချိန်ယူနစ် (လေးပတ်၊ ဆယ်မိနစ်) → တိုင်း .
  • အကြောင်းအရာနှစ်ခု (ကစားသမားနှစ်ဦး၊ တစ်စုံ) → အတိအကျဖော်ပြပါ။ တစ်ခုစီ .
  • နေရာလွတ်ချည်းသက်သက် သို့မဟုတ် စာကြောင်းတစ်ခု၏အဆုံးတွင် (၅ ဒေါ်လာ ___) → ကုန်ကျသည်။ တစ်ခုစီ .
  • အလွန်ကြီးမားသောအုပ်စု၊ "ကမ္ဘာပေါ်ရှိနိုင်ငံတိုင်း" → အဓိပ္ပာယ် တိုင်း .

2.5 · နေ့စဥ်စာရေးရန် & ကိုုအသုံးပြုပါ။

  • စျေးသွား/စျေးဝယ်: "How much are they each?" / "They're 15,000 each."
  • အလုပ်- "Each team member will present for five minutes." / "We meet every Monday."
  • ညွှန်ကြားချက်- "Check each answer before you submit."
  • ရေးပါ အလေးပေးမှု- "Every student deserves a fair chance."
  • ရွှေစည်းမျဉ်း- တစ်ခုစီ / 2 တစ်ခုစီ / တစ်ဦးတည်း → တစ်ခုစီ၊ အုပ်စုတစ်ခုလုံး/ကြိမ်နှုန်း → တစ်ခုစီ။
