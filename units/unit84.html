1.1 · ရည်ရွယ်ချက် & အခြေခံ

ကမ္ဘာမှာ စကားလုံးတစ်လုံးပဲ ပေါ့၊ "ရှိသည်" ( " Hill Street မှာ စားသောက်ဆိုင်အသစ်ရှိတယ် " ) အင်္ဂလိပ်သည္နှစ်ပိုင်း ခွဲခြားသတ်မှတ်သည်။ ဟိုမှာ ရန် ဖြစ်တည်မှုကို မိတ်ဆက်ခြင်း၊ အကြိမ်ကြိမ်ပြောခဲ့သောအရာတစ်ခုလည်း အဲဒါပါပဲ။ ရန် သီးခြားအရာ/အရာတစ်ခုကို ညွှန်ပြသည်။ ရာသီဥတု၊ အချိန်၊ အကွာအဝေးနှင့် It's dangerous to ... ရည်ညွှန်းချက်အတွက် "pseudo" ဘာသာရပ်အဖြစ် လူငယ်များ

There's a new ကော်ဖီဆိုင် near the station. — ဟုတ်ကဲ့ I've been there. It's really nice.
ဝါကျ ၁ တွင် ဆိုင္ဆိုင် (ပထမအကြိမ်) → စတင်မိတ်ဆက် ဟိုမှာ . စာကြောင်း ၂ သည် ထိုအဓိကစားသောက်ဆိုင်အကြောင်း → ဆွေးနွေးတင်ပြ အဲဒါပါပဲ။ .

1.2 · Core ဖော်မြူလာ

THERE + be + noun (+ place/time) → "တစ်ခုခု ရှိနေတယ်" ပြဿနာတစ်ခု လူတွေအများကြီးရှိ၊ ဒီနားမှာ ဘဏ်ရှိ၊ IT + be + adjective / noun → "it" = သီးခြားသိသောအရာ/အရာ အရမ်းကောင်းတယ် အုပ်ချုပ်ရေးယန္တရား IT + be + adj + to V / that ... → dummy subject လမ်းမှာ လျှောက်ရတာ အန္တရာယ် ၊ မင်းမလာနိုင်တာ ရှက်စရာကြီး၊
Government There IT
Present Yes / Yes That's it.
The past there was / there was it was.
finish There is / there is. it has been.
Model will / have / have / have / should have be/be/must be.
Modal done. Whether there is Be that as it may,
grown up There used to be It used to be

⚠️ ဖြင့် ဟိုမှာ ကြိယာ ရှိအတိုင်း ခွဲခြမ်းစိတ်ဖြာ၊ : There is a car / There are two cars။ အတူ အဲဒါပါပဲ။ အမြဲတမ်းအနည်းကိန်း။

1.3 · A. အဲဒီမှာ ... = EXISTS ပြောပါ (ပထမဖော်ပြပါ)၊

  • There's a new restaurant in Hill Street. — မပြောနဲ့ နှစ်သက်ရာအသစ်တစ်ခုသည် Hill Street တွင်ရှိသည်။ .
  • Sorry I'm late. There was a lot of traffic. — မပြောနဲ့ အသွားအလာအများကြီးရှိ၊ .
  • There has been a big rise in prices. (ပြီးသွားသောအခါ ထိုနေရာတွင် အသုံးပြုဆဲ)၊
  • အဲဒါပါပဲ။ = သီးခြားအရာ- We went to the new restaurant. It's very good. (၎င်း = စားသုံးမှု) · They came without calling. It was a complete surprise. (၎င်းတို့၏ဆိုက်ရောက်မှု)
  • တူညီသောဝါကျတွင် ကျွန်ုပ်ပါ- I don't like this town. There's nothing to do here. It's a boring place.
  • ဟိုမှာ When we arrived, there were already a lot of people there. လို့လည်း အဓိပ္ပါယ်ရပါတယ်။

1.4 · B. ရှိမယ် / there must be / there used to be ...

  • Will there be much to do tomorrow?
  • 'Is there a flight to Rome tonight?' 'There might be. I'll check.'
  • If people drove more carefully, there wouldn't be so many accidents.
  • I heard music from the house. There must have been somebody at home.
လူရှုပ်သောလမ်းပေါ်တွင် နေထိုင်စားသောက်ရေး၊ ဆူညံသံတွေ အများကြီးရှိ၊ (ဆူညံသံတွေများနေတယ်) လူရှုပ်သောလမ်းပေါ်တွင် နေထိုင်စားသောက်ရေး၊ အရမ်းဆူညံနေတဲ့ (အဲဒီနေရာက ဆူညံနေတယ်)၊ ဒီရုပ်ရှင်ရုံရှိ ပိတ်သွားပြီ။ (အံကပြဇာတ်တစ်ခုရှိ) ထိုအရာသည် ကူမားကတ်တစ်ခု ရုပ်ရှင်ရုံဖြစ်ခဲ့ဖူးသည် (အရင်က ပြဇာတ်ရုံ)၊

💡 သေချာသည်/နှောင်/ဖြစ်ဖွယ်ရှိသည်..။ = သေသေချာပေါက် ရှိสุก- There's bound to be a car park somewhere. နှင့် There's a flight tonight, but it's sure to be full နှင့်เงาပါ (ထိုနေရာ = ထိုနေရာ)။

1.5 · C ၎င်းသည် အမိုက်စားဘာသာရပ်တစ်ခု၊

  • It + adj + to V : It's dangerous to walk in the road. ( To walk in the road is dangerous ထက် ပိုသဘာဝကျပါတယ် )
  • It didn't take us long to get here. · It's a shame (that) you can't come. · It's not worth waiting.
  • အကွာအဝေး- How far is it from here to the airport?
  • အချိန်/နေ့- What day is it today? It's a long time since we last met.
  • ရာသီဥတု It was windy yesterday. —

2.1 · လက်တွေ့ဘဝအမှတ် 8 ခုု (ဘဝ · အလုပ် · စာမေးပွဲများ)

🚗 Sorry I'm late. There was an accident on the bridge. (ဘဝ - နောက်ကျတဲ့အတွက် တောင်းပန်ပါတယ်)
🏨 Is there a pharmacy near the hotel? (ခရီးသွားလမ်းညွှန်ချက်တောင်း)
🍜 We tried the new noodle bar. It was excellent. (ဘဝ-သုံးသပ်ချက်)
🌧️ It 's cold and there's a strong wind today. (ရာသီဥတု — adjective vs noun)
📈 There has been a sharp increase in house prices. (IELTS Writing Task 1)
💼 There will be a short meeting at 3 p.m. (အလုပ်-မရှိ)
🏙️ There used to be a market here. Now it 's a car park. (ပြောင်းလဲခြင်းဇာတ်လမ်းကို ပြောပြသည်)
🎓 It 's important to read the instructions carefully. (စာမေးပွဲ-မှားယွင်းသောဘာသာရပ်)

2.2 · မှတ်ဉာဏ်လိပ်စာများ 🧠

  • "ရှိပါတယ်" + နာမ်အသစ် → ဖျော်ဖြေ " there is one/ many..." → there ဟုု ဘာသာပြန်လျှင် သေချာပေါက်၊
  • "အဲ" / → အိုင်တီ။ သတ်သတ်မှတ်မှတ်နာမ်တစ်ခုဖြင့် အစားထိုးသည် (စားသောက်ဆိုင်၊ ခရီး...) — အစားထိုးနိုင်သော → it .
  • ကွက်လပ်နောက်ကွယ်တွင် ရှာဖွေရန် လိပ်စာများ နာမ္ → နာမဝိသေသန → အဲဒါပေါ့။ There's a lot of noise / It's noisy။
  • အုိုဘုုအိုင်တီ ရာသီဥတု၊ အချိန်၊ ရက်စွဲ၊ အကွာအဝေးသည် အမြဲတမ်း It ဖြင့် စတင်သည်။
  • တိုင်းရင်းသားလူမျိုးများ "Have" — သတိရပါ - "တစ်နေရာရာမှာရှိတယ်" ဟုပြောရန်အဂၤလိပ်သည် have ကိုမသုံးပါ။ there is ကိုသုံးပါ။

2.3 · အီးမေးလ်လိပ်စာများကို ရယူစမ်းသပ်

  • မှန်/မမှန်သတ်မှတ်- It + be + a/an/some/no+ noun ထိုနာမ် → အများအားဖြင့် There သိုု့ ပြောင်းရမည္။
  • ခွဲဖို့သတိရပါ။ ဖြစ်ဖြစ်၊ အဓိက နောက်ကနာမ်အတိုင်း There were a lot of people.
  • ပြောင်းလဲပါက ၎င်းကို ဤနေရာတွင်ထားပါ- there has been / there will be / there must have been / there used to be .
  • မေးခွန်း - ကျွန်း ဖြစ်ဖြစ်၊ ရှေ့တွင်- Is there ...? Will there be ...? Was there ...?
  • ထောင်ချောက် It's a long way from ... to ... နှင့် It's three years since ... — ဝါကျသည် မှန်ကန်သည် ထိုနေရာတွင် မပြောင်းပါနှင့်။

2.5 · နေ့စဥ်စာရေးရန် & ကိုုအသုံးပြုသည်။

  • စကားပြော- ဧရိယာကို ၁ မိနစ်အတွင်း မိတ်ဆက်ပေးပါ- "ငါ့အိမ်နားက ဈေးတစ်ခုရှိတယ်။ မနက်က အလုပ်များတယ်။ ကော်ဖီဆိုင်တွေ အများကြီးရှိတယ်..."
  • ရေးပါ။ There is/are ... + It shows ... ကိုအသုံးပြု၍ ရုပ်ပုံ/ကားချပ်ကို ဖော်ပြပါ။
  • အလုပ်- စာ- "There'll be a system update tonight. It'll take about an hour."
  • အပြောင်းအလဲဇာတ်လမ်းများ ပြောပြခြင်း- "There used to be ... but now ..." — IELTS Speaking Part 2/3 အတွက် အလွန်အသုံးဝင်သည်။
  • ရွှေကျောင်း- "ဟုတ်ကဲ့" လိုလို့ မပြောခင် သင့်ကိုယ်သင် မေးပါ- သင် (အဲဒီမှာ) အသစ်တစ်ခုခုကို မိတ်ဆက်ပေးနေသလား ဒါမှမဟုတ် သင်သိပြီးသား (အဲဒါ) အကြောင်း ပြောနေတာလား။

🔁 ကြားကာလတွင် ပြောပါ-၊ သုံးရက်၊ နှစ်ရက်နှင့်ရက်ပြီးနောက် ဆရာတော်ကြီးများကို ပြန်လုပ်ပါ။ "ဝါကျမှားပြန်လုပ်ရန်" ခလုတ်ကို . ဆက်စပ် ယူနစ် ၃ (တန်ဖိုးရှိ/မရှိ)၊ ယူနစ် (သေချာသည်/ချည်နှောင်ရန်)၊ ယူနစ်လေ့လာ၇ (+-ing/-ed) ဂီတ
