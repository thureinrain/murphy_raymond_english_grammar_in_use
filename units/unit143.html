1.1 · Objective & အခြေခံအားဖြင့်

တက် အင်္ဂလိပ်လို "productive" အမှုန်အမွှားဖြစ်ပါတယ်။ ဤယူနစ်သည် အုပ်စုအဓိပ္ပာယ်အရ up ဖြင့် အစုအဝေးများကို အုပ်စုဖွဲ့သည်- နီးကပ်လာသည် / လိုက် / လိုက်သည် (go up to, catch up, keep up)၊ စတင်ပါ၊ သတ်မှတ်ပါ။ (set up, take up, fix up)၊ ကြီးပွားတိုးတက် (grow up, bring up)၊ သန့်ရှင်းရေးလုပ်သည် ( tidy up, wash up ) နှင့် အလွန်အသုံးများသော အစုအဝေးအုပ်စု- end up, give up, make up, take up (time/space), turn up, use up .

I grew up in Hue, but after university I ended up working in Saigon.
grow up = ကြီးပွားခြင်း၊ end up = နောက်ဆုံး၊ နောက်ဆုံး (ရလဒ်ကို သေချာပေါက် ကြိုတင်သတ်မှတ်မထားပါ)။

1.2 · Core ဖော်မြူလာ

go /come / walk up (to sb) = နီးလာသည်။ catch up (with sb) = catch sb up = ဖမ်းသည်။ စောင့်ပါ (with sb/sth) · ဆက်ထားပါ! = ဆက်; ဒီအတိုင်း ဆက်သွားပါ။ set up · take up · fix up + ကုမ္ပဏီ / ဝါသနာ / ချိန်းဆိုမှု ကြီးပြင်းလာသည် · ကလေးတစ်ယောက် မွေးဖွားလာ (ကြီးပြင်းလာသည်...) သန့်ရှင်း / ရှင်း / သပ်ရပ်အောင် · ဆေးကြောပါ။ end up + place / + V-ing ငါ ဘူတာမှာ အိပ်နေခဲ့တယ်။ give up (+v-ing/sth) ဆေးလိပ်ဖြတ်သည်။ အလှဖန်တီးရှင် · Women make up 60% နဲ့ဖွဲ့စည်းထားပါတယ်... / ရေနဲ့ဖွဲ့စည်းထားပါတယ်... take up (အချိန်/နေရာ) · turn up / show up · sth up ကိုသုံးပါ။
Meaningful group Group For example
move forward/up go up follow followed Wait a minute. I'll catch up with you.
The beginning set up, take up, fix up He set up his own company.

1.3 · A. ချဉ်းကပ်ပါ၊ အမီလိုက်ပါ၊ ဆက်လုပ်ပါ။

  • တက် / တက် / လမ်းလျှောက် (သို့ ... ) = တစ်စုံတစ်ယောက်/တစ်စုံတစ်ယောက်နှင့် နီးကပ်လာပါ- A tourist came up to me and asked for directions.
  • ဖမ်းသည် (sb) / sb ကိုဖမ်းပါ။ = ရှေ့ကလူကို အမီလိုက်: Go ahead — I'll catch up with you.
  • ဆက်ရန် (sb) = အရှိန်အဟုန်/အဆင့်ကို ဆက်လုပ်ပါ- He speaks too fast — I can't keep up. · ဆက်လက်ပြီးရှိသည်! = ကောင်းသောအလုပ်ကို ဆက်လုပ်ပါ။

1.4 · B. စတင်ရန်၊ သတ်မှတ်ရန်၊ စီစဉ်ပါ။

  • တည်ဆောက်သည် အဖွဲ့အစည်းတစ်ခု / ကုမ္ပဏီတစ်ခု / ဝဘ်ဆိုဒ် / စနစ်တစ်ခု = တည်ထောင်သည်၊ တည်ထောင်ခဲ့သည်- They set up a charity to help street children.
  • ဖယ်ပစ်သည် ဝါသနာ/ အားကစားတစ်ခု = ဝါသနာတစ်ခု စတင်ရန်- My dad took up yoga last year.
  • ပြင်ဆင်ပါ။ အစည်းအဝေး = စီစဉ်- Let's fix up a time to talk.

1.5 · C. ကြီးပြင်းလာ & D. သန့်ရှင်းရေးလုပ်ပါ။

  • ကြီးပြင်းသည် = ကြီးပြင်း၊ ရင့်ကျက်သည်- What do you want to be when you grow up?
  • တင်ပြသည် ကလေး = ပြုစုပျိုးထောင်ခြင်း- She was brought up by her grandparents.
  • ရှင်း/ရှင်း/ရှင်း/ရှင်း (sth) = ရှင်းလင်းရေး- Please tidy up your room.
  • ရေဆေးပါ။ = ထမင်းစားပြီးနောက် ပန်းကန်ဆေးပါ (အင်္ဂလိပ်): I'll cook if you wash up.

1.6 · E. up မှလွဲ၍ အခြားသော အစုအဝေးများ

  • အဆုံးသတ်သည် + နေရာ / + V-ing = နောက်ဆုံး...: We got lost and ended up in a tiny village.
  • အရှုံးပေးသည် = စွန့်စား၊ ဘာပဲလုပ်လုပ် လက်လျှော့လိုက်ပါ။ = abandon: Don't give up! / He gave up his job to travel.
  • မိတ်ကပ် sth = သိမ်းပိုက် (အချိုး); ဖြင့်ဖွဲ့စည်းထားသည်။ = ပါဝင်သည်- Students make up 30% of the population.
  • ဖယ်ပစ်သည် space/time = နေရာယူ/အချိန်ဖြုန်း: This sofa takes up too much space.
  • turn up / ပေါ်လာသည်။ = ပေါ်လာသည်၊ ရောက်ရှိလာသည် (အထူးသဖြင့် မျှော်လင့်ထားသည့်အခါ): He promised to come but never turned up.
  • sth up ကိုသုံးပါ။ = လုံးဝသုံးသည်- Who used up all the hot water?

2.1 · လက်တွေ့ဘဝဥပမာ 8 ခု (ဘဝ · အလုပ် · စာမေးပွဲများ)

2.2 · မှတ်ဉာဏ်အကြံပြုချက်များ 🧠

  • up = "ဦးတည်ရာသို့/ပြီးစီးသည်": သုံးပါ ( use up ) ၊ ရှင်းပါ ( tidy up ) ၊ နောက်ဆုံး ( end up ) ၊ လုံးဝ စွန့်လွှတ်လိုက်ပါ ( give up ) ။
  • up = "up": ကုမ္ပဏီတစ်ခုစတင်ခြင်း ( set up ) ၊ ဝါသနာတစ်ခုစတင်ပါ ( take up ) ၊ ကြီးပြင်းပါ ( grow up ) ။
  • up = "ပိုမိုနီးကပ်စွာ၊ တန်းတူ"- go up to ai၊ catch up with၊ keep up with။
  • phrasal verb → V-ing ပြီးနောက် give up smoking, end up sleeping, take up running
  • ကြီးထွား = ကိုယ်တိုင်၊ ယူလာပါ။ = သူတစ်ပါးကို ယူဆောင်/ချီးမြှောက်ခြင်း။

2.3 · အကြံပြုချက်များကို ရယူစမ်းသပ်ခြင်း။

  • အသုံးများသော passive- was brought up by, is made up of, was taken up by (a table)။
  • IELTS Task 1- make up + ရာခိုင်နှုန်း၊ be made up of + အစိတ်အပိုင်း။
  • catch up WITH , keep up WITH , go up TO — သင့်နောက်တွင် လူများရှိနေသောအခါ ဝိဘတ်များကို မှတ်ထားပါ။
  • "didn't ___ up"+ သည် စောင့်ဆိုင်းနေပါသည် → turn up / ပေါ်လာသည်။ .
  • နာမ်စား- give it up, tidy it up, set it up, use them up, keep it up

2.5 · နေ့စဥ်စာရေးရန် & ကို အသုံးပြုပါ။

  • IELTS စကားပြော "I grew up in… / I took up… last year / I'd like to set up my own…"
  • IELTS Writing Task 1- "Young people make up nearly a third of the population."
  • အလုပ်- "Let's fix up a meeting next week." / "Good job — keep it up!"
  • မိသားစု- "Who's going to tidy up / wash up tonight?"
  • အကြံပြုချက်- ကြီးပြင်းလာ၊ ယူလိုက်၊ အရှုံးပေး၊ အဆုံးသတ်၊ ထူထောင်အသုံးပြုပြီး သင့်ဘဝအကြောင်း စာကြောင်း ၅ ကြောင်းကို ရေးပါ။
