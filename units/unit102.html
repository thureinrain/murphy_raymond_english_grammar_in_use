1.1 · Objective & အခြေခံအားဖြင့်

ဒါကြောင့် နှင့် အဲဒီလို အတွက်အသုံးပြုကြသည်။ အလေးပေး (= အလွန်၊ အမှန်၊ အတိုင်းအတာ)။ တွင်ကွဲပြားသည်။ နောက်ကနေ : ဒါကြောင့် အတူသွားပါ။ နာမဝိသေသန/ကြိယာဝိသေသန တစ်ယောက်တည်း ငြိမ်နေပါ။ အဲဒီလို အတူသွားပါ။ နာမ် (နာမဝိသေသနများဖြင့် သို့မဟုတ် မပါဘဲ)။ မှားယွင်းစွာရွေးချယ်ခြင်းသည် စမ်းသပ်မှုတွင် အလွန်မြင်သာသောအမှားတစ်ခုဖြစ်သည်။

The story was so stupid . — It was such a stupid story .
အယူအဆတူသော်လည်း ဝါကျ ၁ သည် နာမဝိသေသန → နှင့် အဆုံးသတ်သည်။ ဒါကြောင့် ; ဝါကျ ၂ တွင် နာမ် story → ရှိသည်။ အဲဒီလို .

1.2 · Core ဖော်မြူလာ

so + adjective / adverb so good so fast such + (နာမဝိသေသန) + အများကိန်း / ရေမတွက်နိုင်သော နာမ် ဒီလောက်ကောင်းတဲ့ ရာသီဥတုမျိုးက လူတွေ such a/an + (နာမဝိသေသန) + အနည်းကိန်းနာမ် အကောင်းမြင်ဝါဒီ ခွေးကြီးတစ်ကောင် so / such... (that) + result I was so tired (that) I was delieving.
from behind Use it. For example
adjective/adverb (no noun) So Too warm
Singular countable noun Like that Good time · Such an old house
Plural noun Like that Such nice clothes
Uncountable nouns Like that Good weather · Bad coffee.
much / many + noun So Too much traffic · Too many people

⚠️ "a" ၏တည်နေရာ အမြဲရှိနေတယ်။ အဲဒီလို a such ဘယ်တော့မှ a so big dog မရှိပါ။

1.3 · A. So / such သည် အဓိပ္ပါယ်ကို ပိုအားကောင်းစေသည်။

  • so + adj/adv = တကယ်: It's so warm today. He talks so quietly.
  • such (a) + နာမ် = a really ...:We had such a good time. You're such an optimist.

1.4 · B. So ... that / such... that (ရလဒ်သာ)

စာအုပ်က အရမ်းကောင်းတယ် (ဒါဆို) မချနိုင်ဘူး။ သိပ်ကောင်းတဲ့စာအုပ် (အဲဒါကို) မချနိုင်ခဲ့ဘူး။ သာယာတဲ့ ရာသီဥတု (အဲဒါ) ကမ်းခြေမှာ နေ့ရက်တွေကို ကုန်ဆုံးခဲ့ကြတယ်။

အပြောအဆို၊ အဲဒါ ချန်ထားခဲ့တတ်သည်။ အောက်ပါအပိုဒ်ဖြစ်ပါသည်။ ရလဒ် ယခင်အဆင့်၏

  • I didn't realise the house was so old. (= ထိုအရွယ်)
  • I don't usually get up so early. (= ယနေ့အစောပိုင်း)
  • How can you say such a thing? (= ထိုသို့သော အရာ)
  • အဲလိုမဟုတ်ပါဘူး... = မရှိပါ- There's no such word.

2.1 · လက်တွေ့ဘဝဥပမာ 8 ခု (ဘဝ · အလုပ် · စာမေးပွဲများ)

🏖️ We had such a great time in Da Nang. (ဘဝ - အားလပ်ရက်အကြောင်းပြောခြင်း)
☀️ It's so hot today. Let's stay inside. (ဆက်သွယ်ရေး - ရာသီဥတုအကြောင်းပြောခြင်း)
🚗 Sorry I'm late. There was so much traffic. (အလုပ်နောက်ကျတဲ့အတွက် တောင်းပန်ပါတယ်)
📚 It was such an interesting book that I read it in one night. (IELTS Speaking - စာအုပ်များအကြောင်းပြောခြင်း)
😴 The meeting was so long (that) half the team fell asleep. (အလုပ် - ရုံးစကားပြော)
🍜 They serve such delicious food at that restaurant. (ဘဝ - စားသောက်ဆိုင်မိတ်ဆက်)
🙄 How can you say such a thing? (ဆက်သွယ် - ကန့်ကွက်)
📖 Check the dictionary — there's no such word. (စာမေးပွဲ - စကားလုံးမရှိပါ)

2.2 · မှတ်ဉာဏ်အကြံပြုချက်များ 🧠

  • "ဒါက နာမ်နဲ့ ဆိုတော့ တစ်ယောက်တည်းသွား" -အဲလိုတစ်ခုလိုတယ်။ နာမ် "ပွေ့ဖက်" ရန်; ထို့ကြောင့် နာမဝိသေသန/ကြိယာဝိသေသနတစ်ခုသာ လိုအပ်သည်။
  • နာမ်များကို ဖုံးအုပ်ရန် အကြံပြုချက်များ နာမ်ကို သင့်လက်ဖြင့် ဖုံးအုပ်ပါ — ဝါကျသည် "so + adj" နှင့် မှန်နေသေးပါက မူရင်းဝါကျသည် ယင်းကို အသုံးပြုရမည်ဖြစ်သည်။
  • "a" သည် ထိုသို့သောနောက်တွင် အမြဲရပ်တည်နေသည်- Such a / Such an — စကားစုအဖြစ် မှတ်ထားပါ။
  • ရေမတွက်နိုင်သော နာမ်များကို ထောင်ချောက်- ရာသီဥတု၊ အစားအသောက်၊ အကြံဉာဏ်၊ သတင်း၊ ဂီတ၊ အသွားအလာ၊ အလုပ် → အဲဒီလို (မဟုတ်ဘူး)။
  • ရွှေ ၃ တွဲ so long = ဤမျှရှည်လျားသောအချိန် · so far = ဤမျှရှည်လျားသောလမ်း · so much/ many = ဤမျှ (များစွာ)။

2.3 · အကြံပြုချက်များကို ရယူစမ်းသပ်ခြင်း။

  • ကြည့်လိုက် ngay sau စကားစုအဆုံးအထိ blank space- နာမ်တစ်ခုရှိပါသလား။ ဟုတ်ကဲ့ → အဲလို; မဟုတ် → ဒါကြောင့်။
  • ရေတွက်နိုင်သော အနည်းငယ် (a/an) သို့မဟုတ် အများကိန်း/ရေမတွက်နိုင်သော (မရှိ)။
  • Sau → အမြဲရှိနေတယ်။ ဒါကြောင့်
  • ပုံစံ ဝါကျကို ပြန်ရေးပါ။
  • ရွေးပါ။ တစ်ခု အောက်ဖော်ပြပါ နာမဝိသေသနသည် သရဖြင့် အစပြုပါက such an exciting place .

2.4 · ဗီယက်နမ်လူမျိုးများ၏ အဖြစ်များသောအမှားများ ❌/✅

❌ Vietnamese people often talk. ✅ Yes. 🔎 Why?
She is a very beautiful girl. she is Like that A beautiful girl. with noun girl → such a
It was such a great party. it was Like that Good party. Standing behind that.
I had this bad weather. we had Like that Bad weather. The weather is unpredictable.
A useful tip. He gave Like that Useful advice. Advice cannot be counted.
There were many such people. there were A lot. People. A lot → So
I am very tired. I So Tired. noun → so
I haven't seen you in a long time. ...for It's been that long . There is a noun tense.
He speaks English very well. He speaks That's good. English/English speaking ok . English is an uncountable noun.
It was a great day. it was Like that good day. Don't use so a.

2.5 · နေ့စဥ်စာရေးရန် & ကို အသုံးပြုပါ။

  • စကားပြောခြင်း (တစ်နေ့လျှင် ၂ မိနစ်)။ သင့်ပတ်ဝန်းကျင်ရှိ အရာ 3 ခုကို အတွဲလိုက် ချီးမွမ်းပါ- "This coffee is so good. It's such good coffee."
  • စာရေးခြင်း (တစ်နေ့လျှင် စာကြောင်း ၅ ကြောင်း) ရလဒ်ကိုဖော်ပြရန် so/such ... that ... ဖွဲ့စည်းပုံကို အသုံးပြု၍ အတွေ့အကြုံတစ်ခုကို ပြောပြပါ။
  • အလုပ်တွင်- "Thank you — it was such a helpful meeting." / "Sorry, there was so much traffic."
  • IELTS စကားပြော ပိုမိုသဘာဝကျပြီး စိတ်ခံစားမှုရှိသောဝါကျအတွက် "very" ကို so/ ထိုသို့ဖြင့် အစားထိုးပါ- "It was such a memorable trip."
  • ရွှေစည်းမျဉ်း- စကားမပြောခင် တိတ်တိတ်လေးမေးပါ။ "ဒါဆို နာမ်တွေရှိလား"

🔁 ကြားကာလတွင် လေ့ကျင့်ပါ- ၃ ရက်၊ ၇ ရက်နှင့် ၁၄ ရက်ပြီးနောက် လေ့ကျင့်ခန်းများကို ပြန်လုပ်ပါ။ မရေမတွက်နိုင်သော နာမ်များဖြင့် ဝါကျများကို အာရုံစိုက်ပါ။ ဆက်စပ်- ယူနစ် ၁၀၃ (လုံလောက်/လွန်း)၊ ယူနစ် ၁၀၄ (အတော်လေး/အစား)၊ ယူနစ် ၁၀၇ (as ... as)။
