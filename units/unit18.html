UNIT 18 - လုပ်ရန်သုံးသည်

1.1 · ရည်ရွယ်ချက်များ & အနှစ်သာရ

+ V ကိုသုံးတယ်။ တစ်ခုခုအကြောင်းပြောနေတာ ပုံမှန်ဖြစ်လေ့ရှိတယ်။ သို့မဟုတ် အမှန်ဖြစ်ခဲ့ဖူးသည်။ အတိတ်၌သော်လည်း အခု မမှန်တော့ဘူး။ . ဗီယက်နမ်- "used to ..." ၊ "in the past ..."

I used to play tennis a lot, but I don't play very much now.
အရင်က အများကြီး ကစားဖူးတယ် → အခု သိပ်မကစားဘူး။ ဝါကျက a အတိတ် ↔ ပစ္စုပ္ပန် ဆန့်ကျင်ဘက်။

1.2 · Core ဖော်မြူလာ

(+) S + used to + base verb I used to live in Hue. (-) S + မသုံးခဲ့ဘူး + V သူ့ကို သဘောကျဖို့ မသုံးခဲ့ဘူး ။ (S + used not to + V — also ok) ကျွန်တော် သူ့ကို မကြိုက်ဖူး။ S + တစ်ခါမှ + V လက်ဖက်ရည်ကို မကြိုက်ဖူး။ (?) Did + S + use to + V? အချိုတွေ အများကြီးစားဖူးလား။ အတိတ်၌သာ။ ပစ္စုပ္ပန်အတွက် "I use to do" မရှိပါ → ပစ္စုပ္ပန် ရိုးရှင်းပါသည်။
past (used) Present (Present Simple)
I used to play. He played.
We lived. We live.
I used to have. There is / there is.

⚠️နောက် လုပ်/မလုပ်ဘူး။ ရေးပါ။ အသုံးပြုရန် (ဃ) — "did you go" ကဲ့သို့ အတိတ်အမှတ်အသားကို သယ်ဆောင်ထားပြီးဖြစ်သောကြောင့် "did you went" မဟုတ်ပါ။

1.3 · A. အတိတ်အလေ့အထများ

  • David used to spend a lot of money on clothes. These days he can't afford it.
  • 'Do you go to the cinema much?' 'Not now, but I used to.' (= ကျွန်တော် သွားခဲ့ဖူးသည်) — "used to" တွင် ရပ်နိုင်သည်။

1.4 · B. အတိတ်က အချက်အလက်/ပြည်နယ်များ

  • This building is now a furniture shop. It used to be a cinema.
  • I used to think Mark was unfriendly, but now I realise he's very nice.
  • I've started drinking tea recently. I never used to like it before.
  • There used to be four cinemas in the town. Now there is only one.

1.5 · C. သုံးသည် vs လုပ်နေသည်။

usually do. I'm doing it.
It's true that repetition is no longer a habit. Do something on time.
I Often viewed. Lots of TVs. I was watching. When I got to the TV, Rob called.

1.6 · D. လုပ်ရန်အလေ့အထနှင့် မရောထွေးပါနှင့် (ယူနစ် 61)

+ V is used. + V-ing is used.
I use... (no longer correct) I use... (familiar, no longer strange/difficult)
I used to live alone (Now I'm not alone anymore) I I live. alone (being alone is familiar)

1.7 · လက္ခဏာများနှင့် ဘုံအမှားများ

Signal For example
"but now ... / these days / any more / no longer" she used to Smoking, but she's gone.
When I was young/at school/last year (habit) When I was young used to Swimming in the river.
❌ Wrong. ✅ That's right.
I used to get up early. (current) I usually get up Early.
Have you ever played football? are you to use Play football?
I never liked fish. I don't do it. to use Like a fish.
She lived in Hue. She used it. Live In Hue
I went to Paris in 2019. (once) I went To Paris in 2019

စာအုပ်ရှိလင့်ခ်များ- ယူနစ် ၆ (အတိတ်အဆက်မပြတ်) · ယူနစ် ၃၆ (Would = သုံးသည်) · ယူနစ် ၆၁ (လုပ်/လုပ်ပါ)။

2.1 · လက်တွေ့ဘဝဥပမာ 8 ခု (နေ့စဉ်ဘဝ · အလုပ် · စာမေးပွဲများ)

🛵 I used to ride a bicycle to school. (ကလေးဘဝပုံပြင်)
🏬 This shopping mall used to be a market. (မြို့အပြောင်းအလဲကို ဖော်ပြသည်)
☕ I didn't use to like coffee, but now I drink it every day. (အလေ့အကျင့်ပြောင်းလဲခြင်း)
🏡 Did you use to live in the countryside? (IELTS Speaking အပိုင်း ၁)
📺 There used to be only one TV channel. (အတိတ်နှင့် ပစ္စုပ္ပန် နှိုင်းယှဉ်မှု)
💼 She used to work as a nurse. Now she's a manager. (လုပ်ဖော်ကိုင်ဖက်တစ်ဦးနှင့် မိတ်ဆက်ပေးခြင်း)
🎮 — Do you play video games? — Not now, but I used to . (အတိုချုံးအဖြေ)
🌳 I never used to enjoy walking, but now I love it. (အရသာပြောင်း)

2.2 · မှတ်ဉာဏ်အကြံပြုချက်များ 🧠

  • used to = "in the past ... but not now" - ပစ္စုပ္ပန်နှင့် ဆန့်ကျင်ဘက် အမြဲရှိနေသည်။
  • "d" တစ်ကြိမ်သာပေါ်လာသည်- used to (အတည်ပြု) — did ... use to / didn't use to (လုပ်ထားပြီးသား)။
  • to + base verb သုံးတယ်။ ; + V-ing ကို သုံးတယ်။ . "be" → add -ing ဖြင့်။
  • လက်ရှိပုံစံမရှိပါ- အလေ့အထတစ်ခုအကြောင်းကို ယခုပြောပြရန် → usually + present simple ကိုသုံးပါ။

2.3 · စာမေးပွဲ အကြံပြုချက်များ 🎯

  • စာကြောင်းနှင့်အတူ "but now / these days / any more" → ပထမပိုင်းကို မကြာခဏ သုံးတယ်။
  • မေးခွန်းများနှင့် အနုတ်လက္ခဏာများ- အဖြေနှင့်အတူ ရွေးချယ်ပါ။ အသုံးပြုရန် (ဃ) လုပ်ပြီးနောက်။
  • လုပ်ရပ်တစ်ခု ဖြစ်ပျက်နေသည်။ တစ်ကြိမ်သာ သို့မဟုတ် သတ်မှတ်ထားသောအကြိမ်အရေအတွက် ( three times ) → အသုံးမဝင်သောအတိတ်ကိုအသုံးပြုပါ။
  • အမြန်ထူးခြားချက်- I'm used to ... (အကျွမ်းတဝင်) / I used to ... (ကျင့်သုံးသည်)။

2.4 · ဗီယက်နမ် သင်ယူသူများ၏ အဖြစ်များသော အမှားများ ❌/✅

❌ Vietnamese researchers often say. ✅ That's right. 🔎 Why?
I drink milk every morning. I usually Drink Milk every morning Not useful at the moment.
Have you ever smoked? are you to use Smoking? After doing → Use.
I used to play badminton. I used to play Badminton. To + base verb is used.
I usually get up early. I'm used to it. Acquisition. Get up early. + V-ing is used.
I have been to Japan twice. I visited. Japan twice. A specific number of times → Past Simple.
There used to be a movie theater here. I used to have. Be Here is the cinema. there + be (translated "there was")
She never ate meat. She didn't. to use Eat meat. After not → not used.
He previously lived in Da Nang. He used Live In Da Nang Not extra.

2.5 · နေ့စဉ်စကားပြော & အရေးအသား ✍️ အသုံးချပါ။

  • IELTS စကားပြော ကလေးဘဝ / မွေးရပ်မြေအကြောင်း → "I used to ..., but now ..." သည် သဘာဝခြားနားမှုကို ပေးသည်။
  • "past vs present" စာကြောင်း ၅ ကြောင်းရေးပါ။ သင့်အကြောင်း- အသွင်အပြင်၊ ဝါသနာ၊ နေရာ၊ အစားအသောက်၊ အလုပ်။
  • မြို့ကိုဖော်ပြခြင်း- "There used to be lots of trees here. Now there are tall buildings."
