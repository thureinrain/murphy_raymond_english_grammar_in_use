UNIT 38 – ငါလုပ်ရင် … ငါလုပ်ရင် …

1.1 · ရည်မှန်းချက်များနှင့် သဘာဝ

အကြောင်းပြောကြရအောင် ပစ္စုပ္ပန်/အနာဂတ် ဒါပေမယ့် နည်းလမ်းနှစ်ခုရှိပါတယ်။ ငါလုပ်ရင် ငါလုပ်မယ်... အဲ့ဒီအခါ တကယ်ဖြစ်လာနိုင်တယ်။ ; ငါလုပ်ရင်... ညွှန်လိုက်တာ စိတ်ကူးပါ။ (ဖြစ်မလာဘူး မမျှော်လင့်ထားဘူး)။ if clause ထဲက ကြိယာ အတိတ် ဒါပေမယ့် အဓိပ္ပါယ်ရှိတယ်။ အတိတ်မဟုတ်ပေ။ .

(Undecided) If we go by bus, it will be cheaper.
(Decided to take the train) If we went by bus, it would be cheaper.
မေးခွန်း 1- ဘတ်စ်ကားစီးရန် ဖြစ်နိုင်သေးသည်။ မေးခွန်း 2- ဘတ်စ်ကားမစီးဖို့ သေချာသိပါ → စိတ်ကူးကြည့်ပါ။

1.2 · Core ဖော်မြူလာ

ဖြစ်နိုင်သည်- အကယ်၍ + ပစ္စုပ္ပန်ရိုးရှင်းသော၊ will / can / may + V ငါ့နာရီကို မင်းရှာတွေ့ရင် ငါ့ကို ဖုန်းဆက်လို့ရမလား စိတ်ကူးကြည့်ပါ- If + ရိုးရှင်းသော အတိတ်၊ would / could / might + V ပိုက်ဆံအိတ်တွေ့ရင် ဘာလုပ်မလဲ။ be: I / he / she / it was or were if clause တွင် would ကိုမသုံးပါနှင့် (တရားဝင်ကျေးဇူးတင်တာကလွဲလို့ ၊ မင်းလိုချင်ရင် ကျေးဇူးတင်မှာပါ…)

1.3 · ဖြေ

  • အဲဒါကို ဟောပြောသူက မြင်တယ်။ ဖြစ်နိုင်သေးသည်။ → ငါတို့သွားလျှင် …၊ အဲဒါ ပါလိမ့်မယ်။ …
  • အဲဒါကို ဟောပြောသူက သိတယ်။ ဖြစ်မလာဘူး။ → သွားခဲ့လျှင် …၊ အဲဒါ ပါ့ (If we go မပြောနဲ့)

1.4 · B. If + past = စိတ်ကူးယဉ် (အတိတ်မဟုတ်)၊

  • What would you do if you won a lot of money? (အနိုင်ရဖို့တကယ်မမျှော်လင့်ခဲ့ပါဘူး)
  • If there was / were an election tomorrow, who would you vote for? (xem ယူနစ် 39C)
  • နှိုင်းယှဉ်- If you find my watch, can you call me? (တွေ့နိုင်သည်) ≠ If you found a wallet in the street, what would you do? (စိတ်ကူးပါ)

1.5 · C. if clause တွင် would ကို မသုံးပါနှင့်

တစ်စုံတစ်ယောက်က ငါ့ကို သေနတ်နဲ့ ချိန်ရင် ငါ အရမ်းကြောက်သွားလိမ့်မယ်။ (မဟုတ်ပါ တစ်စုံတစ်ယောက်က ထောက်ပြလျှင်) ဘတ်စကားနဲ့သွားရင်တော့ ပိုသက်သာမယ်။ (မဟုတ်: ငါတို့သွားမယ်ဆိုရင်) ခြွင်းချက် - တရားဝင် ကျေးဇူးတင်ပါသည်- မင်းရဲ့ဆုံးဖြတ်​ချက်​ကို​ပြောပြရင်​​တော့ ​ကျေးဇူးတင်​ပါတယ်​။

1.6 · D. Main clause: would / could / might

  • If I went to bed now, I wouldn't sleep. · Would you mind if I used your phone?
  • If I won a lot of money, I might buy a house. (ဖြစ်နိုင်သည်)
  • If it stopped raining, we could go out. (= နိုင်မယ်)

2.1 · လက်တွေ့ဘဝဥပမာ 8 ခု (ဘဝ · အလုပ် · စာမေးပွဲများ)

🎰 If I won the lottery, I 'd buy my parents a house. (စိတ်ကူးကြည့်ပါ — IELTS Speaking)
🗺️ If you turn left at the lights, you 'll see the museum. (လမ်းညွှန်-အမှန်တကယ်)
⌚ If you find my glasses, can you call me? (ဖြစ်နိုင်ပါတယ်)
👛 If you found a wallet in the street, what would you do? (အယောင်ဆောင်မေးခွန်း)
🚗 I can't afford a car. If I bought one, I 'd have to borrow money. (ဘဝ - မလုပ်သင့်တဲ့ အကြောင်းပြချက်)
☔ If it stopped raining, we could go for a walk. (could = လုပ်နိုင်တယ်)
📨 I would be grateful if you would reply by Friday. (တရားဝင်အီးမေးလ် — ခြွင်းချက် if clause တွင်ရှိမည်)
🤝 Would you mind if I opened the window? (တောင်းပန်ပါတယ် အရမ်းယဉ်ကျေးပါတယ်)

2.2 · မှတ်ဉာဏ်အကြံပြုချက်များ 🧠

  • "Step back for a moment = step back from reality" : present → past (if clause), will → would (main clause)။
  • if clause မှာ would မရှိပါ။ - ကျန်အပိုင်းတွင်သာ ရှိပါမည်။
  • သင့်ကိုယ်သင် မေးပါ- "Is it really possible?" Yes → I do / will. မ/ခက်ခဲ → If I did/ would.
  • ငါသာ မင်းဖြစ်ခဲ့ရင်... အကြံပြုချက် (ယူနစ် ၃၉)။

2.3 · အကြံပြုချက်များကို ရယူစမ်းသပ်ခြင်း။

  • ဘာသာရပ် "given" We've decided not to … " → ရေးပါ။ ငါတို့ + V-ed ဆိုရင်... (သွားရင်တော့ မဟုတ်ဘူး)။
  • အပိုင်း ၂ ပိုင်းခွဲပါ- တစ်ဖက်တွင် would ကိုကြည့်ပါ → if side ဖြစ်ရမည်။ ရိုးရှင်းသောအတိတ် .
  • အဖြေမှာ If … would … ("grateful if you would" မှလွဲ၍) → အမျိုးအစား .
  • I/he/she/it ဖြင့် ဖြစ်ခဲ့သည်။ နှင့် ခဲ့ကြသည် အားလုံးမှန်ပါသည်၊ တရားဝင်စာရေးရာတွင် ဦးစားပေးထားသည်။ ခဲ့ကြသည် .

2.4 · ဗီယက်နမ်လူမျိုးများ၏ အဖြစ်များသောအမှားများ ❌/✅

❌ Vietnamese people often talk. ✅ Yes. 🔎 Why?
If I have a lot of money, I will travel. If I am there were. I got a lot of money, I will travel. A would → if clause uses the past.
I will tell you if I know. If I am I know. I will say Not in the if clause.
If you are rich, you will buy a car. If I am rich, I am Pat buy a car It's like the past wants to be.
If he asks me, I will help him. If he is he asked. I'd like to help Not in the if clause.
If I were you... If I am were you... Standard form
What would you do if you won? What? Pat Would you do it if you won? Both sides must be compared.
If you have time, you can go. If I am there were. time i can go Not in the if clause.
If you see Lan, tell him. you see Lan, Tell him. The if clause uses the present simple.

2.5 · နေ့စဉ် စကားပြောနှင့် စာရေးခြင်း ✍️ အသုံးချပါ။

  • စကားပြောခြင်း (တစ်နေ့လျှင် ၂ မိနစ်)။ "What would you do if…?" (ထီပေါက်၊ ဖုန်းပျောက်၊ ၁လ လျှော့သွားသည်) မေးခွန်း ၃ ခု ဖြေပါ။
  • ဘာကြောင့်မလုပ်ရလဲဆိုတာ ရှင်းပြပါ "I'm not going to move. If I moved, I'd have to find a new school for my kids."
  • အလုပ်အီးမေးလ်- "I would be grateful if you would confirm the meeting time."
  • IELTS Speaking Part 3- "If the government invested more in public transport, fewer people would drive."
  • ရွှေစည်းမျဉ်း- အမှန် → ငါလုပ်ရင်၊ → ငါလုပ်ရင် စိတ်ကူးကြည့်ပါ။

🔁 ကြားကာလတွင် လေ့ကျင့်ပါ- ၃ ရက်၊ ၇ ရက်နှင့် ၁၄ ရက်ပြီးနောက် လေ့ကျင့်ခန်းများကို ပြန်လုပ်ပါ။ "Redo the wrong sentence" အချိန်တိုင်း။ ဆက်စပ်- ယူနစ် ၂၅ (အကယ်၍ ဘယ်အချိန်)၊ ယူနစ် ၃၆ (ပါ့)၊ ယူနစ် ၃၉ (သိခဲ့ရင်/ငါဆန္ဒရှိမယ်)၊ ယူနစ် ၄၀ (သိခဲ့ရင်ပေါ့)။
