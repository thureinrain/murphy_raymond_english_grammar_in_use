1.1 · ရည်မှန်းချက်များနှင့် သဘာဝ

ယူနစ် ၃၉ အကြောင်းကို စိတ်ကူးယဉ်သည်။ ပစ္စုပ္ပန် ; Unit 40 အကြောင်းကို စိတ်ကူးယဉ်ကြည့်ပါတယ်။ အတိတ် - အရာများ ဖြစ်မလာဘူး။ (ဒါမှမဟုတ် ငါတို့နောင်တရလို့ တစ်ခုခုဖြစ်သွားတာ)။ ကျွန်ုပ်တို့ "step back one step" : ရိုးရှင်းသောအတိတ် → အတိတ်ပြီးပြည့်စုံမှု (had + V3) .

Last week Nam was ill, but his friend Hoa didn't know. Later she said:
If I'd known you were ill, I would have visited you.
အမှန်တရား- သူမ မသိဘူး → မလည်ပတ်ခဲ့ပါ။ . နှစ်ဖက်စလုံးက အတိတ်ကဖြစ်ခဲ့ပြီး ပြောင်းလဲလို့မရတဲ့အရာတွေအကြောင်း ဆွေးနွေးကြပါတယ်။

1.2 · Core ဖော်မြူလာ

If + S + had + V3 ... , S + would / could / might + have + V3 စောစောက ထွက်သွားရင် ဘတ်စ်ကားကို ဖမ်းမိလိမ့်မယ်။ (အမှန်က ငါ စောစောမထွက်သွားဘူး) S + ဆန္ဒ + S + had + V3 (အတိတ်အတွက် နောင်တရ) ပိုကြိုးစားလေ့လာစေချင်တယ်။ (အမှန်တကယ်တော့ ခက်ခက်ခဲခဲ မလေ့လာခဲ့ဘူး)
reality (past) If... (Imagine), I wish ...

⚠️ 'd' တွင် အဓိပ္ပါယ်နှစ်မျိုးရှိသည်။ If I'd seen = ငါ ရှိခဲ့ပါတယ်။ မြင်ခဲ့သည် (နောက်ပိုင်း V3) · I'd have said = ငါ ပါ့ ရှိသည် (နောက်ပိုင်းတွင်)။

1.3 · A. If + had done = အတိတ်ကို မြင်ယောင်ကြည့်ပါ။

  • I didn't go out last night. I would have gone out if I hadn't been so tired.
  • စဉ်ဆက်မပြတ်ပုံစံကို သုံးနိုင်သည်- If he had been looking where he was going, he wouldn't have fallen.
  • ပစ္စုပ္ပန် ↔ အတိတ်ကို နှိုင်းယှဉ်ပါ- I'm not hungry. If I was hungry, I'd eat. / I wasn't hungry. If I had been hungry, I'd have eaten.

1.4 · B. if clause တွင် would ကို မသုံးပါနှင့်

ငါ မင်းကိုတွေ့ခဲ့ရင် နှုတ်ဆက်ခဲ့လိမ့်မယ်။ ✅ ငါ မင်းကို တွေ့ဖူးရင် နှုတ်ဆက်ခဲ့မယ်။ ❌

1.5 · C. Wish + had done = တစ်စုံတစ်ခု (မဖြစ်ခဲ့) နောင်တရခြင်း။

  • I wish I'd known about the sale. (= မသိခဲ့ပါဘူး အခုတော့ နောင်တရမိတယ်)
  • I feel terrible. I wish I hadn't said that. (= ငါပြောတယ်)
  • Do you wish you'd gone to university?
  • မသုံးပါနဲ့။ ရှိမှာလား။ sau ဆန္ဒ- I wish it had been warmer (❌ I wish it would have been warmer )။

1.6 · D. Will Do vs would have done (ရောနှောထားသော အခြေအနေအရ)

if clause (past); the result Result time
If you went to bed early last night I It won't happen. I am tired. Present
If you went to bed early last night I No sleep. . The past

1.7 · E. would have / could have / might have

ရာသီဥတုက မဆိုးဘူးဆိုရင် ငါတို့ အပြင်ထွက်ကြလိမ့်မယ်။ (သေချာသွားပြီ) ငါတို့ထွက်သွားနိုင်တယ်။ (= သွားနိုင်သည်) ငါတို့ထွက်သွားနိုင်တယ်။ (= ဖြစ်နိုင်ပါတယ်)

2.1 · လက်တွေ့ဘဝဥပမာ 8 ခု (ဘဝ · အလုပ် · စာမေးပွဲများ)

2.2 · မှတ်ဉာဏ်အကြံပြုချက်များ 🧠

  • "Step back two steps" : အတိတ်အဖြစ်မှန် (ပြုသည်) → စိတ်ကူးစိတ်သန်း (ပြုသည်)။ ရလဒ်အပိုင်း- would + have + V3
  • ဖော်မြူလာ 3-3- အမျိုးအစား 3 = V3 ရှိသည်။ + V3 ရှိမယ်။ - နှစ်ဖက်စလုံးတွင် V3 ရှိသည်။
  • 'd- ကိုကုဒ်ဆွဲခြင်း d ရဲ့နောက်မှာ V3 → ရှိခဲ့; d ရဲ့နောက်မှာ ရှိသည် သို့မဟုတ် V integer → would.
  • ပြောင်းပြန်လှန်ခြင်း- တကယ်တော့ "did" → ဆန္ဒ/if "hadn't done" ; တကယ်တော့ "didn't do" → "had done" ။

2.3 · အကြံပြုချက်များကို ရယူစမ်းသပ်ခြင်း။

  • ကြည့်ပါ။ မနေ့ည / မနေ့က / ငယ်ငယ်တုန်းက + ယူဆချက် → အမျိုးအစား ၃။
  • ဟိုဘက်ကမ်းက ဟိုမှာ +V3 ရှိမယ်။ → အပိုဒ် လိုအပ်လျှင် ရှိသည် + V3 .
  • ရှိသည် ယခု ရလဒ်အပိုဒ်တွင် if clause သည် အတိတ်အကြောင်း → ဆွေးနွေးသည်။ would + V (ရောနှော)။
  • ဆောင်းပါးက ဝါကျကို ပြန်ရေးသည်- "X ဖြစ်သွားတယ်။ ဘာဖြစ်လို့လဲဆိုတော့ Y " → " ဆိုလျှင် မဟုတ်ဘူး Y၊ X ရှိမည်မဟုတ်ပါ။ ဖြစ်ခဲ့သည်" (နှစ်ဖက်စလုံးက အတည်ပြု/ငြင်းဆိုသည်)။
  • အဖြေက ဟုတ်တယ် would have ngay sau အကယ်၍ သို့မဟုတ် ဆန္ဒ → အမျိုးအစား။

2.5 · နေ့စဉ် စကားပြောနှင့် စာရေးခြင်း ✍️ အသုံးချပါ။

  • ညနေဒိုင်ယာရီ တစ်နေ့တာအတွင်း တစ်ခုခုအကြောင်း I wish I had / hadn't … စာကြောင်း ၁ ကြောင်းရေးပါ။
  • လုပ်ငန်းအတွေ့အကြုံမှ သင်ယူခြင်း- If we had tested the app more, we wouldn't have had so many bugs.
  • IELTS Speaking အပိုင်း 2- "a decision you regret" → စာကြောင်း 2-3 အမျိုးအစား 3 ခုနှင့် ရောနှောထားသော ဝါကျတစ်ခုကို သုံးပါ။
  • ကျွမ်းကျင်စွာပြောပါ- would've /ˈwʊdəv/၊ wouldn't've ၊ I'd've အသံများကို စာဖတ်လေ့ကျင့်ပါ။

🔁 ကြားကာလတွင် လေ့ကျင့်ပါ- အောက်ပါလေ့ကျင့်ခန်းကို ပြန်လုပ်ပါ။ ၃/၇/၁၄ ရက် had V3 ↔ would have V3 အတွဲများကို အာရုံစိုက်ပါ။ ဆက်စပ်- ယူနစ် ၁၅ (ပြီးပါပြီ)၊ ယူနစ် ၃၉ (လောလောဆယ်တော့ အစစ်မဟုတ်ပါ)၊ ယူနစ် ၄၁ (ဆန္ဒ)။
