UNIT 115 – မဟုတ်လျှင်; နေသရွေ့; ပေးသည်/ပေးသည်။

Self-study theory · မတူညီသောအလေ့အကျင့် · အကြိမ်များစွာ စမ်းသပ်ပါ။
ပြီးဆုံးပြီ- 0 ကြိမ် အမြင့်ဆုံး ရမှတ်- သိမ်းထားသော မှားနေသော ဝါကျများ- 0 ရမှတ် ၅၂ ခု + ကိုယ်တိုင်ရေးထားသော မေးခွန်း ၄ ခု

1.1 · Objective & အခြေခံအားဖြင့်

ဤယူနစ်သည် စကားလုံးအုပ်စုနှစ်စုဖြင့် အခြေအနေဆိုင်ရာဝါကျများကို ချဲ့ထွင်သည်-

  • မဟုတ်လျှင် = မဟုတ်လျှင် = except if (≈ if … not )။
  • ကြာသရွေ့ / so long as / provide (that) / provide (that) = ပေးသည်၊ ပေးသည်။ (≈ only if )။
This gym is for members only. You can't use it unless you're a member.
= သင်သာဝင်နိုင်သည်။ ရှိရင် အဖွဲ့ဝင်ဖြစ်သည်; ထိုမှတပါး၊ မရှိ။

1.2 · Core ဖော်မြူလာ

မဟုတ်လျှင် ... + S + V (အတည်ပြု) = ... if + S + မဟုတ် + V အမြန်မတက်ရင် ဘတ်စ်ကားကို လွတ်သွားလိမ့်မယ်။ = ... မလျင်မြန်ဘူး။ ... ကာလပတ်လုံး / so long as + S + V = အခြေအနေအရသာ ... … ပေးသည် (ထို) / ပေးသည် (ထို) + S + V ⚠️ အနာဂတ်အကြောင်းပြောခြင်း- ဤစကားလုံးများ၏နောက်တွင် အလိုဆန္ဒကို မသုံးပါနှင့် → ပစ္စုပ္ပန်ကိုသုံးပါ။
from Meaning For example
If not If not I will come If not I'm busy.
as long as / so long as as long as can stay as long as You are silent.
give (that) conditions and (more formal) provided. You pay on time, There is no fee.
paying (that) with conditions Serving. The room is clean. I don't mind.

1.3 · A. Unless = လွဲလျှင်

  • I'll see you on Friday unless I have to work late. (အလုပ်နောက်ကျလျှင်)
  • Unless you have a car, it's hard to get there.
  • 'Should I tell Mum?' 'Not unless she asks.' (= အမေမေးလျှင်သာ)
  • He wouldn't complain unless it was really bad.
  • Let's take a taxi — unless you'd rather walk.

လဲလှယ်နိုင်ကြပါသည်။ မဟုတ်လျှင် ⇄ မဟုတ်ရင် :

ငါတို့ အခုထွက်သွားရင် ငါတို့နောက်ကျလိမ့်မယ်။ = ငါတို့ အခုမထွက်ရင် နောက်ကျမယ်။

1.4 · B. As long as / provides / providing = နေသမျှကာလပတ်လုံး

You can borrow my laptop as long as you bring it back tomorrow.
Cycling to work is great, provided there's somewhere safe to leave your bike.
Providing the price is reasonable, we'll buy it.
နောက်အပိုင်းကတော့ မဖြစ်မနေ အခြေအနေများ : အဲဒီအခြေအနေရှိတယ်ဆိုရင် နောက်တစ်ခုက အဆင်ပြေသွားမှာပါ။

1.5 · C. အနာဂတ်အတွက် အလိုဆန္ဒကို မသုံးပါနှင့်

မိုးမရွာရင် အပြင်မထွက်ဘူး။ ❌ မလုပ်ရင် ရပ်သွားမယ်။ ရာသီဥတုကောင်းရင် ပျော်ပွဲစားထွက်မယ်။ ❌ ရာသီဥတုက ပံ့ပိုးပေးမယ်။

1.6 · အလွယ်တကူ ရှုပ်ထွေးနေသော ဖွဲ့စည်းပုံများနှင့် နှိုင်းယှဉ်ပါ။

sentence Meaning
I will play tennis tomorrow. If not It rains. Rain → Don't play.
I will play tennis tomorrow. gives Not looking for rain. no rain → play (synonymous, different words)
I will play tennis tomorrow. But It rains. While playing in the rain (Unit 112);
Take a racket. in case We play tennis. case (unit 114);
❌ Sai shop ✅ Yes.
If you don't hurry, you will be late. If you put it quickly You will be late.
If it doesn't rain, I'll go. If I don't know, I'll go. It's raining. .
You can go out after finishing your homework. (means as long as) You can go out. as long as You have done your homework.
As long as you help me... As long as you stay Help I,…
To pay... provided. (It's) what you pay...

စာအုပ်ရှိလင့်ခ်များ- ယူနစ် ၂၅ (if/when + present) · ယူနစ် ၃၈-၄၀ (စည်းကမ်းသတ်မှတ်ချက်) · ယူနစ် ၁၁၂ (သော်လည်း) · ယူနစ် ၁၁၄ (ခဲ့လျှင်)။

2.1 · လက်တွေ့ဘဝဥပမာ 8 ခု (ဘဝ · အလုပ် · စာမေးပွဲများ)

🚌 You'll miss the bus unless you leave now. (ဘဝ - သတိပေးချက်)
🎟️ You can't enter unless you have a ticket. (ပွဲ-စည်းကမ်း)
🚗 You can borrow my car as long as you drive carefully. (မိသားစု — သတ်မှတ်အခြေအနေများ)
💼 You can work from home provided you attend the Monday meeting. (အလုပ်-မူဝါဒ)
🏨 Providing the room is clean, I don't mind which hotel we choose. (ခရီးသွားသဘောတူညီချက်)
📺 I don't watch TV unless there's nothing else to do. (IELTS Speaking - အလေ့အထ)
💰 I can lend you the money as long as you pay me back next month. (သူငယ်ချင်း - ပိုက်ဆံချေး)
☎️ Don't call me unless it's urgent. (အလုပ်-အကြံဉာဏ်)

2.2 · မှတ်ဉာဏ်အကြံပြုချက်များ 🧠

  • unless = un + less → အဓိပ္ပါယ် "မဟုတ်လျှင်"; သူ့ကိုယ်သူ အနှုတ်လက္ခဏာ → နောက်အပိုဒ် ဆီသို့ အတည်ပြုပါ။ .
  • as long as = "နေသမျှကာလပတ်လုံး" (ဗီယက်နမ်လို "သရွေ့" ကဲ့သို့)။
  • ပေးသည် / ပေးသည်။ = ကာလပတ်လုံး စာရွက်စာတမ်းများနှင့် စာချုပ်စာတမ်းများတွင် အသုံးပြုလေ့ရှိသည်။
  • အမြန်ပြောင်းလဲမှု- unless X = if not X ; as long as X = only if X ။
  • ကြိုက်လျှင်- အလိုမရှိ။ နောက်ကွယ်။

2.3 · အကြံပြုချက်များကို ရယူစမ်းသပ်ခြင်း။

  • ရွေးပါ။ unless / as long as : အောက်ပါဝါကျကိုဖတ်ပြီး “ဒါက ခြွင်းချက် (မသိရင်) ကောင်းတယ်။ လိုအပ်သောအခြေအနေများ (နေသရွေ့)?"
  • unless … doesn't သည် မကြာခဏ ထောင်ချောက် (အနှုတ် နှစ်ဆ) — အဓိပ္ပာယ်ကို သေချာစစ်ဆေးပါ။
  • ဝါကျကို "… or …" ( Hurry or you'll be late ) → You'll be late unless you hurry. ပြန်ရေးပါ
  • "… only if …" → The dog bites only if … → The dog won't bite unless … မဟုတ်လျှင် အနှုတ် + ဖြင့် ပြန်ရေးပါ။
  • ဤစကားများအားလုံးပြီးနောက် ပစ္စုပ္ပန်ကာလ အနာဂတ်အကြောင်းပြောတဲ့အခါ။

2.4 · ဗီယက်နမ်လူမျိုးများ၏ အဖြစ်များသောအမှားများ ❌/✅

❌ Vietnamese people often talk. ✅ Yes. 🔎 Why?
If you don't study, you will fail. If studied You will fail. Unless it has a negative connotation
I will come if I am not busy. If not... m busy. If you don't have it, you won't want it later.
You can live without silence. … as long as You are silent. Necessary condition → As long as it exists
As long as it doesn't rain, we'll go. As long as it lasts No. Rain,... Present instead of future
pay me It's convenient. provided. You pay... gave / gave not given
Unless you're quick, you'll be late. If you don't know You hurry... Except does not contain clauses of this type.
As long as you're happy, I'm happy. long as you are happy... The second "as" is missing.
If you don't go, I won't leave. I don't change. If not you go. If you don't use it, it's shorter.

2.5 · နေ့စဥ်စာရေးရန် & ကို အသုံးပြုပါ။

  • သင့်ကလေးနှင့်အတူ အခြေအနေများ သတ်မှတ်ပါ- "You can play games as long as you finish your homework first."
  • အလုပ်အီးမေးလ်- "The project will be completed by Friday, provided we receive the data on time."
  • လိမ္မာပါးနပ်စွာငြင်းပါ- "I'd rather not go unless you really need me."
  • IELTS- "Unless governments take action, pollution will get worse."
  • ရွှေစည်းမျဉ်း- "မဟုတ်ရင်" မဟုတ်လျှင် → "နေသရွေ့" → နေသမျှကာလပတ်လုံး / ပေးထားသည်။
