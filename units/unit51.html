1.1 · ရည်ရွယ်ချက်များ & အနှစ်သာရ

အရန်ကြိယာများ be, have, do, can, will, should, would... "help" ကဲ့သို့သော tenses၊ မေးခွန်းများနှင့် အနှုတ်လက္ခဏာဆောင်သည့် အဓိကကြိယာ။ ဆက်သွယ်ရေးတွင်၊ မိခင်ဘာသာစကားသည် အရန်ကြိယာကို အသုံးပြုသည်။ ၎င်း၏ကိုယ်ပိုင်အပေါ် ရန် ဝါကျတစ်ခုလုံးကို ထပ်ခါထပ်ခါ ရှောင်ကြဉ်ပါ။ - အဖြေတိုတိုများ၊ ဆန့်ကျင်မှုများ၊ စိတ်ဝင်စားမှုကိုပြသခြင်း၊ သဘောတူခြင်း (So do I) နှင့် I think so / I hope not ကဲ့သို့သော စာကြောင်းများ။

"Have you locked the door?" — "Yes, I have ." (= I have locked the door)
Gary wasn't working, but Laura was .
အရန်ကြိယာများသည် စောစောကဖော်ပြခဲ့သော ကြိယာစကားစုတစ်ခုလုံးအတွက် ရပ်တည်သည်။

1.2 · Core ဖော်မြူလာ

အကူဝါကျ → ပြန်သုံးသည် : can → can , have → have , was → was ပစ္စုပ္ပန်/အတိတ် ရိုးရှင်းသော (အရန်မရှိ) → do/dos/do အတိုချုံးအဖြေ / ဆန့်ကျင်ဘက် : ဟုတ်တယ်၊ ငါ့မှာရှိတယ်။ /မဟုတ်ဘူး၊ ငါမဟုတ်ဘူး။ / ဟုတ်တယ် ငါလုပ်ခဲ့တယ်! စိတ်ပါဝင်စားမှုပြသခြင်း- သင်ရော ရှိပါသလား။ / သူမ မဟုတ်ဘူးလား? / ဒါလား။ သဘောတူညီချက် (+) : So + auxiliary + S ငါလည်း ဒီလိုပါပဲ။ / ပေါလုလည်း ဒီလိုပါပဲ။ သဘောတူညီချက် (−) : Neither/Nor + auxiliary + S I./ Nor Can I. = S + negative auxiliary + တစ်ခုခုကို ငါမလုပ်ဘူး။ think/hope... : ငါထင်တယ် ။ / မမျှော်လင့်ပါဘူး။
Original sentence Reuse the backup. Sample reply
I'm tired. I So I I. / Are you? Don't laugh.
I never read a newspaper. Do (simply submit) No? do it I
I passed the exam. did (past simple) So I did. I. / You? well done!
I can't swim. can No? can I. / Can't you? I can do it.
I have been to Japan. there is So there is I. / have you? when?

1.3 · A. စာစုတစ်ခုလုံးအတွက် အရန်ကြိယာများ

  • Jessica could lend me the money, but she won't. (= ငါ့ကို ပိုက်ဆံမချေးဘူး)
  • ပစ္စုပ္ပန်/အတိတ် ရိုးရှင်းသောအသုံးပြုမှု လုပ်/လုပ်/လုပ် : "Do you like onions?" "Yes, I do." / "Does Simon live in London?" "He did, but he doesn't any more."

1.4 · B. ဆန့်ကျင်ဘက် (ငြင်းဆို)

အများအားဖြင့် ပြင်းထန်သော ဖိစီးမှုရှိသော အခြားသူ၏ဝါကျနှင့် ဆန့်ကျင်ဘက်ဖြစ်သော အရန်ကြိယာကို သုံးပါ-

"You're sitting in my place." — "No, I'm not." "You didn't lock the door." — "Yes, I did!" "You never listen to me." — "Yes, I do!"

1.5 · C. စိတ်ပါဝင်စားမှု/အံ့အားသင့်မှုပြသခြင်း- သင်ရော ရှိပါသလား။ သူမ မဟုတ်လား။

  • "I've just seen Stephen." — "အိုး၊ မင်းရှိလား။ ? သူ ဘယ်လိုလဲ?"
  • "Lisa isn't very well today." — "အိုး၊ သူမ မဟုတ်လား။ ? ဘာမှားလို့လဲ?"
  • "It rained every day." —" လုပ်ခဲ့တယ်။ ? ရှက်စရာကောင်းတယ်!"

အပြုသဘောဆောင်သောဝါကျ → အပြုသဘောဆောင်သော နောက်ဆက်တွဲမေးခွန်း ( have you? ); အနှုတ်ဝါကျ → အနုတ်လက္ခဏာ နောက်ဆက်တွဲမေးခွန်း ( isn't she? )။ မေးခွန်းတဂ်များ (ယူနစ် 52) နှင့် ကွဲပြားသည်။

1.6 · D. So / Neither / Nor (သဘောတူညီချက်)

  • ဒီတော့ + ဆွယ် + S (အပြုသဘောဝါကျ): "I'm tired." "So am I." / I passed and so did Paul. (မဟုတ်ပါ။ ပေါလုပြု၏။ )
  • Neither/Nor + auxiliary + S (နှုတ်ဝါကျ): "I never read newspapers." "Neither do I."
  • သို့မဟုတ် ၎ + နှုတ်ဆွယ် + လည်းကောင်း : "I don't know." "I don't either."
  • မှတ်ချက်- ပြီးနောက် တစ်ခုခုကို မသုံးပါနှင့် အခိုင်အမာ အရန် (Neither do I၊ မဟုတ်ပါ။ ငါလည်းမလုပ်ဘူး။ ).

1.7 · E. ငါထင်တယ် / ငါမျှော်လင့်တယ် / ငါမကြောက်ဘူး...

positive. A common mistake
I think / I hope. I Don't do it Think / I Don't do it I hope so.
I hope / I fear / I think I hope No / I'm afraid No / I guess No
I think so I don't think so. Or I don't think so.

⚠️ "Do you think it will rain?" — "I hope not." (မပြောနဲ့ ငါဒါကိုမမျှော်လင့်ပါဘူး။ ) I'm afraid so/not = ကံမကောင်းစွာဖြင့် ဟုတ်/မဟုတ် (သတင်းဆိုး)။

1.8 · အလွယ်တကူ ရှုပ်ထွေးနေသော တည်ဆောက်ပုံများ & ဘုံအမှားများနှင့် နှိုင်းယှဉ်ခြင်း။

yes/no (agreement) do you have / do you? (interest) Question Mark (Unit 52)
the purpose "me too" "really?" Confirm one's own statement
For example I'm hungry. — Me too. I'm hungry. — are you Are you hungry? Aren't you?
❌ Wrong. ✅ That's right.
"I like tea." "So I do." “So do i do ."
"I'm not hungry." "Neither I am." "No? Am I? ."

"I went home early." "So was I." “So I did. I am."
"Will it rain?" "I don't hope so." “I Don't expect. ."
"Is she coming?" "I think." "I think So ."

စာအုပ်ရှိလင့်ခ်များ- ယူနစ် ၅၂ (မေးခွန်း tags) · ယူနစ် ၄၉ (မေးခွန်းများ) · နောက်ဆက်တွဲ ၇ (AmE : ထင်တာပဲ)။

2.1 · လက်တွေ့ဘဝဥပမာ 8 ခု (နေ့စဉ်ဘဝ · အလုပ် · စာမေးပွဲများ)

☕ "I need a coffee." — " So do I ." (ရုံး-သဘောတူညီချက်)
🎤 "I can't sing at all." — " Neither can I ." (ကာရာအိုကေ — အနှုတ်သဘောတူစာချုပ်)
✈️ "I've just come back from Japan." — "Oh, have you ? How was it?" (စကားဝိုင်း - စိတ်ဝင်စားမှုပြသခြင်း)
🔒 "You didn't lock the door." — "Yes, I did !" (မိသားစု - ဆန့်ကျင်ဘက်)
☔ "Is it going to rain?" — "I hope not ." (နေ့စဉ်ဘဝ - မမျှော်လင့်နဲ့)
🏨 "Have you got a room for tonight?" — "I'm afraid not . We're full." (ဝန်ဆောင်မှု — ယဉ်ကျေးစွာ သတင်းဆိုးပေးခြင်း)
📈 "Will we get a bonus this year?" — "I expect so ." (အလုပ် - ခန့်မှန်းချက်)
🎓 Minh passed the exam and so did his sister. (စာမေးပွဲများ – ပြောင်းပြန်လှန်ခြင်း)

2.2 · မှတ်ဉာဏ်အကြံပြုချက်များ 🧠

  • "Spot the auxiliary" : မူရင်းဝါကျတွင် အရန်အရန် မည်သည့်အရာကိုမဆို၊ တစ်ခုမှမရှိရင် do/does/did ကို မှန်ကန်တဲ့ tense ကိုသုံးပါ။
  • ထို့ကြောင့်/မဟုတ်ပါ + ပြောင်းပြန်- So am I, Neither do I — မေးခွန်းစကားလုံးအစီအစဉ်ကဲ့သို့။
  • အပျက်သဘောဆောင်သော အဓိပ္ပါယ်ကိုလည်း မဆောင်ကြနှင့် → ကတိသစ္စာပြုပြီးနောက် အရန်။
  • မျှော်လင့်ချက် / ကြောက် / မှန်းဆ → "not" ; စဉ်းစား / မျှော်လင့် → "don't ... so" .
  • မင်းရှိလား။ / ဒါလား။ = "Really?" — အခြားသူ၏ဝါကျနှင့် တူညီသော အပြုသဘော/အနုတ်လက္ခဏာပုံစံကို ထားရှိပါ။

2.3 · စာမေးပွဲ အကြံပြုချက်များ 🎯

  • auxiliary တွင်ဖြည့်ပါ- သိရန် ပထမအပိုဒ်ကိုဖတ်ပါ။ တင်းမာ နှင့် အပြုသဘော/အပျက်သဘော ဒုတိယအပိုဒ်သည် အများအားဖြင့်၊ ဆန့်ကျင်ဘက် : I wasn't tired, but my friends were.
  • "but" → အများအားဖြင့် အပြုသဘော ↔ အနှုတ်ကို ကူးပြောင်းသည်။
  • never, hardly, nobody နှင့် စာကြောင်းများ အနုတ်လက္ခဏာ → သဘောတူသည်။ မဟုတ်ဘူးလား။ : "I never eat meat." "Neither do I."
  • စာကြောင်းများနှင့်အတူ 'ဃ :I'd like = ငါ → ဒါဆို ပါ့ ငါ; I'd seen = ငါ → ဒါဆို ရှိခဲ့ပါတယ်။ ငါ။
  • သတင်းဆိုးကို အတည်ပြုခြင်း → I'm afraid so ; သတင်းဆိုး → I'm afraid not ငြင်းဆိုခြင်း။

2.4 · ဗီယက်နမ် သင်ယူသူများ၏ အဖြစ်များသော အမှားများ ❌/✅

❌ Vietnamese researchers often say. ✅ That's right. 🔎 Why?
"I'm tired." "Me too I am." " Me too . " / "Me too." So the structure of + auxiliary + S
"I like pho." "So I like." “So do it I am." Present simple → do.
"I don't smoke." "Me too." " neither do I . " / "Neither am I." Negative sentence → neither
"I didn't go." "Neither didn't I." "No? I did. I am." There is no double negative.
"I saw that film." "So was I." “So I did. I am." past simple → I did.
"Will he come?" "I don't hope so." “I Don't expect. ." Expected → Not expected.
"Is it true?" "I think it." "I think So ." Use so instead of clause.
"I think not so." “I Don't think ." I think he refused
"You were late!" "No, I didn't!" “No, I am It wasn't. !" It must have coincided with the auxiliary.
"I've finished." "Oh, are you?" “Oh, there is you?" I = I have → You have?

2.5 · နေ့စဉ်စကားပြော & အရေးအသား ✍️ အသုံးချပါ။

  • စကားလေးများ သူငယ်ချင်းတစ်ယောက်က သင့်အား တစ်ခုခုပြောသည့်အခါတိုင်း Did you? / Have you? / Is it? နှင့် နောက်ဆက်တွဲမေးခွန်းတစ်ခုကို ပြန်ဖြေကြည့်ပါ — စကားဝိုင်းကို ပိုမိုသဘာဝကျစေသည်။
  • အမြန်သဘောတူညီချက်- အရန်ကိုရွေးချယ်ခြင်း၏တုံ့ပြန်မှုကိုလေ့ကျင့်ရန် "Me too" ကို So do I / So am I / Neither can I ဖြင့်အစားထိုးပါ။
  • အလုပ်- မသေချာသောမေးခွန်းများကို ဖြေပါ- "I think so, but let me check." / "I don't think so."
  • ရွှေစည်းမျဉ်း- စာပြန်သောအခါ၊ သင့်ကိုယ်သင် "What auxiliary, tense and positive/negative does that sentence use?" မေးပါ။
