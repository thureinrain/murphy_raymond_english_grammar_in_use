1.1 · Objective & အခြေခံအားဖြင့်

ယူနစ် 42 သည် is done / was done တွင်ရပ်သည်။ ဤယူနစ်သည် အတင်းအကျပ် ချဲ့ထွင်သည်။ ကျန်အချိန်များနှင့် ဖွဲ့စည်းပုံအားလုံး . မပြောင်းလဲသောအခြေခံမူများ- be (သင့်လျော်သောပုံစံ) + V3 . "be" သည် ထိုဖွဲ့စည်းပုံတွင် မည်သို့သောပုံသဏ္ဍာန်ရှိသည်ကို သိရန်လိုအပ်ပါသည်။ ဖြစ် , ဖြစ်ခဲ့သည်။ မြက်ပင် ဖြစ်ခြင်း။ .

Somebody is repairing the lift. → The lift is being repaired .
Somebody has repaired the lift. → The lift has been repaired .
Somebody will repair the lift. → The lift will be repaired .

1.2 · Core ဖော်မြူလာ

Sau modal / to: (to) be + V3 can be done, will be done, to be done Modal + perfect: (to) have been + V3 ပြီးသင့်ပြီ၊ ပြီးသွားနိုင်တယ်။ ပစ္စုပ္ပန် ပြီးပြည့်စုံမှု- have / has been + V3 ပြီးပါပြီ။ အတိတ်ပြီးပြည့်စုံမှု- ဖြစ်ခဲ့ + V3 ပြီးပြီ။ လက်ရှိစဉ်ဆက်မပြတ်- am / is / are being + V3 ကို လုပ်ဆောင်နေပါသည်။ Past continuous- was / were being + V3 ကို လုပ်ဆောင်နေပါသည်။

1.3 · A. ပြီးပြီ (sau modal, to, going to)

  • Something must be done before it's too late.
  • A mystery is something that can't be explained.
  • I want to be left alone. (to + be + V3)

1.4 · B. ပြီးပြီ (modal + perfect)

  • အတိတ်အကြောင်း မှန်းဆချက် / should / could: The parcel might have been sent to the wrong address.
  • အခြေအနေပေးဝါကျများတွင် 3- If you had locked the car, it wouldn't have been stolen. အမျိုးအစား
  • Sau ယောင်/ပေါ်လာ- The problems seem to have been solved.

1.5 · C. ပြီးပြီ / ပြီးပြီ။

  • Have you heard? The match has been cancelled. · Have you ever been bitten by a dog?
  • The soup tasted awful. It had been cooked too long. (အတိတ်ကာလတစ်ခုမတိုင်မီ)

1.6 · D. လုပ်ဆောင်နေသည်/ လုပ်ဆောင်နေပါသည်။

  • ဖြစ်ခြင်း/ဖြစ်ခြင်း။ စကားပြောတဲ့အချိန်မှာ : I think we are being followed. · (in a shop) No thanks, I'm being served.
  • ဖြစ်ခြင်း/ဖြစ်ခြင်း။ အတိတ်ကာလတစ်ခုတွင် : The room was being cleaned when I arrived.

2.1 · လက်တွေ့ဘဝဥပမာ 8 ခု (ဘဝ · အလုပ် · စာမေးပွဲများ)

2.2 · မှတ်ဉာဏ်အကြံပြုချက်များ 🧠

  • ဖော်မြူလာ "BE ထည့်သွင်း"- တက်ကြွသောဝါကျကို ယူပါ၊ အရန်ကြိယာအပိုင်းကို သိမ်းဆည်းပါ၊ ထို့နောက် ထည့်သွင်းပါ။ ဖြစ်/ဖြစ်/ဖြစ်ခြင်း။ + V3- will clean → will be cleaned; has cleaned → has been cleaned; is cleaning → is being cleaned။
  • ↔ ရှိပြီ ↔ ဖြစ်ခြင်း၊ have/has/had ပြီးနောက် ဖြစ်ခဲ့သည်။ ; am/is/are/was/were ပြီးနောက် ဖြစ်ခြင်း။ .
  • Modal + be + V3- can be, must be, should be, will be — ဘယ်တော့မှ "be" လက်လျှော့လိုက်ပါ။

2.3 · အကြံပြုချက်များကို ရယူစမ်းသပ်ခြင်း။

  • ကြည့်ပါ။ ယခု / လောလောဆယ် + အကြောင်းအရာသည် အရာဝတ္ထု → ဖြစ်သည်။ is/ are being + V3 .
  • ကြည့်ပါ။ already / just / ever / since / for + passive → has/have + V3 .
  • ကြည့်ပါ။ အခုမှ / ကြာပြီ sau should/might → ဖြစ်သင့်/ဖြစ်နိုင်သည် + V3 .
  • they / somebody ဖြင့် ဝါကျကို ပြန်ရေးပါ- တူညီသော tense ကိုထားပါ၊ passive voice သို့ ပြောင်းလိုက်ပါ။
  • နာမ်အဆုံးသတ်များ -able / -ible = can be + V3 : ဆေးကြောနိုင်သော၊ စားသုံးနိုင်သော၊ ခရီးဆောင်။
