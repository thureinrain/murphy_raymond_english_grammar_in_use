1.1 · Objective & အခြေခံအားဖြင့်

အပိုင်း ၂ ပြန်ရောက်ပါပြီ။ တက် အဖွဲ့ ၄ ဖွဲ့ အပါအဝင်၊ (၁) စိတ်ကူး၊ အကြောင်းအရာ — ပြည်နယ်၊ တီထွင်မှု၊ တီထွင်မှု (bring up, come up, come up with, make up ); (၂) စိတ်ခံစားမှု၊ငွေ၊ရာသီဥတု — ပျော်ရွှင်ပါစေ၊ ကယ်တင်ပါ၊ စိတ်အေးပါ (cheer up, save up, clear up ); (၃) ပျက်စီးခြင်း။ (blow up, tear up, beat up ); (၄) အခြားအစုအဖွဲ့ (break up, do up, look up, put up with, hold up, mix up)။

I didn't know the word, so I looked it up . — Good idea. Who came up with it?
look sth up = ရှာဖွေမှု (အဘိဓာန်၊ ကွန်ရက်); come up with = စိတ်ကူး(အကြံဥာဏ်)။

1.2 · Core ဖော်မြူလာ

အကြောင်းအရာ/စိတ်ကူး bring sth up (= born up) · sth comes up (= ကြီးပြင်းလာသည်) + အကြံ/အစီအစဥ်ဖြင့် ပေါ်လာသည် · make sth up (= make up) စိတ်ခံစားမှု/ငွေ/ရာသီဥတု ရွှင်လန်းတက်ကြွ · ရွှင်လန်းစေသော sb up · save up for sth / to do sth · ရှင်းသွားသည် ဖျက်ဆီးပါ။ blow up (ပေါက်ကွဲသည်) · blow sth up · tear sth up · beat sb up တခြား break up / split up (with sb) · do up (coat; building) · look sth up put up with sth · hold sb/sth up · mix up / get sb ရောထွေးသည်။ နာမ်စားများ- ယူလာပါ · မျှော်ကြည့် · ဆုတ်ဖြဲ · သူမကို အားပေးပါ (NO: ကြည့်လိုက်ပါ) စကားလုံး 3 လုံး- come up with · put up with · save up for → အရာဝတ္ထုသည် စကားစုတစ်ခုလုံးပြီးနောက် လာပါသည်။

1.3 · A. နိုင်ငံတော်၊ စဉ်းစား၊ တီထွင်

  • တင်ပြသည် ခေါင်းစဉ်တစ်ခု = တင်ဆက်ပါ၊ ပုံပြင်တစ်ပုဒ်တင်ပြပါ- Please don't bring up money at dinner.
  • အပေါ်တက်ခဲ့ပါ = (အကြောင်းအရာ) ဖော်ပြခဲ့သည်- Your name came up in the meeting.
  • တက်လာပါ။ အကြံဥာဏ် / အစီအစဉ် / အဖြေ = We need to come up with a better plan. ဖြင့် ပေါ်လာသည်။
  • sth up လုပ်ပါ။ = ဖန်တီးထားသည်- That story isn't true — he made it up.

1.4 · B. အားပေးပါ၊ ငွေစုပါ၊ ရာသီဥတုရပ်တန့်ပါမည်။

  • ပျော်ပျော်နေပါ = ရွှင်လန်းပါစေ။ ပျော်ရွှင်ပါစေ sb up = တစ်ယောက်ယောက်ကို ပျော်ရွှင်အောင်လုပ်ပါ- Cheer up! It's not the end of the world.
  • save up for sth / to do sth = ငွေစုသည်- I'm saving up for a new laptop.
  • ရှင်းလင်းပါ။ (ရာသီဥတု) = သာယာကြည်လင်သော၊ It rained all morning, but it cleared up after lunch.

1.5 · C. ဖျက်ဆီးခြင်း၊ ပျက်စီးခြင်း။

  • မှုတ်ပါ။ = ပေါက်ကွဲ၊ ဘာပဲလုပ်လုပ် မှုတ်လိုက်ပါ။ =explode- The bridge was blown up during the war.
  • မျက်ရည်ကျတယ်။ = ဖျက်စီးထားသည်- She tore up the letter without reading it.
  • sb ကိုရိုက်ပါ။ = တစ်စုံတစ်ဦးကို ပြင်းထန်စွာ ဒဏ်ရာရစေသည်- He was beaten up by a gang.

1.6 · D. up မှလွဲ၍ အခြားသော အစုအဝေးများ

  • ကွဲ/ကွဲ (sb)၊ = chia tay: She broke up with her boyfriend last month.
  • တက်လုပ်ပါ။ a coat / buttons / shoelaces = ချည်နှောင်ရန်၊ တက်လုပ်ပါ။ a building/room = remodel: They bought an old flat and did it up.
  • ဘာပဲလုပ်လုပ် မျှော်ကြည့် (အဘိဓာန်တွင်၊ အွန်လိုင်း) = ရှာရန်- Look it up on your phone.
  • sth နှင့်အတူတက် = သည်းခံ: I can't put up with this noise any longer.
  • sb/sth ကို ကိုင်ထားပါ။ = နှောင့်နှေး- Sorry I'm late — I was held up in traffic.
  • ရောမွှေပါ။ / get sb/sth ရောထွေးလိုက်ပါ။ = ဤအရာနှင့် ရောထွေးနေသည်- People often mix up the twins.

2.1 · လက်တွေ့ဘဝဥပမာ 8 ခု (ဘဝ · အလုပ် · စာမေးပွဲများ)

💡 Our team came up with a great idea for the campaign. (အလုပ် - အဖွဲ့အစည်းအဝေး)
📖 If you don't know a word, look it up . (လေ့လာပါ - စကားလုံးများကို ရှာဖွေပါ)
🚗 Sorry I'm late. I was held up in traffic. (ဘဝ-တောင်းပန်ပါတယ်)
🔊 I can't put up with the noise from the building site any more. (တိုင်ကြား)
💰 I'm saving up for a trip to Japan. (IELTS Speaking - အစီအစဉ်)
💔 They broke up after five years together. (ဆက်သွယ်ရေး- အချစ်ဇာတ်လမ်း)
😊 She was feeling down, so we took her out to cheer her up . (သူငယ်ချင်း)
🏠 They bought an old house in the Old Quarter and did it up . (အိမ်)

2.2 · မှတ်ဉာဏ်အကြံပြုချက်များ 🧠

  • up = "အပေါ်ယံသို့ လွင့်ပါ"- ခေါင်းစဉ်ပေါ်လာသည် (come up)၊ ခေါင်းစဉ်ပေါ်လာသည် (bring up)၊ စိတ်ကူးပေါ်လာသည် (come up with)၊ "bring up" (look up) ဟူသော စကားလုံးကို ရှာကြည့်ပါ။
  • up = "တိုး": ခံစားချက် ( cheer up ) ၊ ငွေစု ( save up ) ၊ ကောင်းကင်ပြာ ( clear up ) ။
  • up = "ကွဲအက်သည်" blow up, tear up, beat up, break up
  • စကားလုံး ၃ လုံး၏ စကားစု ခွဲခြား၍မရပါ- come up with, put up with, save up for — အရာဝတ္ထုသည် အမြဲနောက်ဆုံးဖြစ်သည်။
  • မိတ်ကပ် story = "ဖန်တီးမှု" သည် မမှန်သော ဇာတ်လမ်းဖြစ်သည်။

2.3 · အကြံပြုချက်များကို ရယူစမ်းသပ်ခြင်း။

  • အသုံးများသော passive- was held up, was blown up, was beaten up, has been done up။
  • "tolerate" → အတူတက် ; "think of an idea" → တက်လာပါ။ ; "invent (a story)" → မိတ်ကပ် .
  • စကားလုံး 2 လုံးပါသော နာမ်စားများ → look it up, tear it up, make it up, cheer him up ကြားတွင် ညှပ်ထားသည်။
  • မိုးလေဝသ + "hope it…soon" → ရှင်းလင်းသည်။ (လောလောဆယ်တော့ အပလီကေးရှင်း ပြီးလို့ အဆင်ပြေပါတယ်)။
  • get mixed up : I got their names mixed up = နောက်ဆုံး နာမည်မှားသွားတယ်။

2.5 · နေ့စဥ်စာရေးရန် & ကို အသုံးပြုပါ။

  • အဖွဲ့အစည်းအဝေး- "Can anyone come up with a better solution?" / "I'd like to bring up one more point."
