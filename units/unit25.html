1.1 · ရည်မှန်းချက်များ & ပင်မစိတ်ကူး

အနာဂတ်အကြောင်းပြောတဲ့အခါ ဝါကျတစ်ကြောင်းရှိတတ်တယ်။ နှစ်ခုသဘောပေါ့။ : the main clause (အသုံးပြုခြင်း။ ပါလိမ့်မယ်။ လိုအပ်သော၊ သွားရန်…) နှင့် စတင်သည့် အချိန်/အခြေအနေ အပိုဒ် when, if, before, after, until, as soon as, while . ဤယူနစ်၏ရွှေစည်းမျဉ်း- when/if… clause တွင် will ကိုမသုံးပါနှင့် , ကိုသုံးပါ။ ပစ္စုပ္ပန်ရိုးရှင်း (သို့မဟုတ် ပစ္စုပ္ပန် ပြီးပြည့်စုံသော) ဟူသော အဓိပ္ပာယ်မှာ အနာဂတ်ပင် ဖြစ်သည်။ ခွဲခြားတတ်အောင်လည်း သင်တယ်။ ဘယ်တော့လဲ (သေချာပါတယ်) မှ အကယ်၍ (ဖြစ်နိုင်သည်)။

I'll phone you when I get home.
အဓိကအပိုဒ်- ငါ မင်းကို ဖုန်းဆက်လိုက်မယ်။ (will) · when clause: ငါအိမ်ပြန်ရောက်တဲ့အခါ (ပစ္စုပ္ပန်ရိုးရှင်းသည်၊ when I will get မဟုတ်ပါ။

1.2 · Core ဖော်မြူလာများ

Main clause (အနာဂတ်) + Time/ condition clause will / will not / go to / imperative when / if / before / after / until / as soon as / while + ရိုးရှင်းသော ပစ္စုပ္ပန် (သို့မဟုတ် ပြီးပြည့်စုံသော ပစ္စုပ္ပန်) မိုးတိတ်ရင် ငါတို့ အပြင်ထွက်မယ်။ (ဘယ်တော့ ရပ်မှာလဲ) ငါပြန်လာတဲ့အထိ ဒီမှာစောင့်။ (ငါမလာမချင်း) ပြီးတာနဲ့ ငါ မင်းကို ဖုန်းဆက်လိုက်မယ်။ (အရင်ဆုံးပြီးရင် ဖုန်းဆက်လိုက်ပါ)

1.3 · A. when… clause သည် ပစ္စုပ္ပန်ရိုးရှင်းမှုကို အသုံးပြုသည်။

  • When you are in London again, come and see us. (When you will be မဟုတ်ပါ)
  • (ကလေးတွေကို) What do you want to be when you grow up? မေးပါတယ်။
  • I'm going back on Sunday. Before I go, I'd like to see the museum.

1.4 · B. Present perfect after when / after / until / as soon as

သုံးပါ။ ပြီးပြီ။ ပထမ လုပ်ဆောင်ချက်ကို အလေးထားပါ။ လုံးဝပြီးသွားပြီ ဒုတိယ မတိုင်ခင်

အဲဒီစာအုပ်ကို ပြီးသွားတဲ့အခါ ငှားလို့ရလား။ Kate ကိုဖုန်းဆက်ပြီး ညစာစားလို့ရတယ်။ (ဖုန်းဆက်ပြီး → ပြီးရင် ထမင်းစား) ကိတ်ကိုဖုန်းဆက်လိုက်တဲ့အခါ သူ့အကြောင်းမေးမယ်။ (နှစ်ခုလုံးကို တချိန်တည်း → မသုံးပါနှင့်)

💡 မကြာခဏဆိုသလို နှစ်ခုစလုံး အဆင်ပြေသည်- I'll come as soon as I finish / I've finished.

1.5 · C. if → ပစ္စုပ္ပန် ရိုးရှင်းပြီးနောက် အနာဂတ်အတွက်

အပြင်ထွက်ရင် ရေစိုမယ်။ (ငါတို့သွားမလို့လား) ထပ်ဖြစ်ရင် ဒေါသထွက်မယ်။ (ဖြစ်မလာဘူး) ငါတို့ မမြန်မြန်ရင် နောက်ကျလိမ့်မယ်။

1.6 · D. ဘယ်အချိန် သို့မဟုတ် အကယ်၍

when if
Meaning It will definitely happen. Could happen (not sure)
For example I'm leaving later. when I'll go out and get some bread. Maybe leave. If I'll go out and get some bread.

2.2 · မှတ်ဉာဏ်အကြံပြုချက်များ 🧠

  • "When/If don't like Will" 🚫 — ဒီစကားလုံးတွေဟာ ဘယ်တော့မှ တိုက်ရိုက်မတည်မြဲပါဘူး (အနာဂတ်ကာလ / အခြေအနေတွေကို ပြောတဲ့အခါ)။
  • "no will" စာရင်း- when if before after until as soon as while
  • ပြီးပြီ။ after when/after/until/as soon as = "finished completely, then…" .
  • when = သေချာသည်။ (ပြန်လာမယ်၊ ပြန်လာမယ်) · if = ဖြစ်နိုင်တယ်။ (နောက်ကျနိုင်ပြီး မိုးရွာနိုင်သည်)။

2.3 · စာမေးပွဲ အကြံပြုချက်များ 🎯

  • ကွက်လပ် 2 ခုပါသော ဝါကျတစ်ခု- အပိုဒ်ကို ရှာပါ။ ဘယ်တော့/ဖြစ်/ဖြစ်/ရောက်တဲ့အထိ… → ပစ္စုပ္ပန်ကာလ; အခြား clause → will.
  • "Joining two sentences" : ဆန္ဒအပိုဒ်ကို ၎င်းအတိုင်းထားပါ၊ အခြားတစ်ခုကို ရိုးရိုးရှင်းရှင်းတင်ပြရန် / ပစ္စုပ္ပန်စုံလင်စေရန် အခြားတစ်ခုကို ပြောင်းပါ။
  • မသေချာပါက → မသေချာပါက "is this sure to happen?" ကိုမေးပါ။ အကယ်၍ .
  • မှတ်ချက်- "I don't know when he will come" သည် မှန်နေသေးသည် — ၎င်းသည် အချိန်အပိုဒ်မဟုတ်ဘဲ သွယ်ဝိုက်သောမေးခွန်းဖြစ်သည်။

2.4 · ဗီယက်နမ်စပီကာများ ❌/✅ အဖြစ်များသောအမှားများ

2.5 · နေ့စဉ်စကားပြော & စာရေးခြင်း ✍️ ၎င်းကို အသုံးချပါ။

  • စာပို့ခြင်း- "I'll call you when I'm free." / "Let me know if you need anything."
  • အလုပ်အီးမေးလ်- "I'll update you as soon as I hear from the client."
  • IELTS စကားပြော အစီအစဉ်များအကြောင်းပြောနေသည်- "When I finish university, I'm going to work abroad."
  • ကိုယ်တိုင်စစ်ဆေးခြင်း- when/if ရေးပြီးတိုင်း နောက်စကားလုံးကို တစ်ချက်ကြည့်လိုက်ပါ — will ဖြစ်ပါက ပြင်ပါ။
